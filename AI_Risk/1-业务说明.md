# 物流行业风控系统业务说明文档

## 1. 典型欺诈场景

### 1.1 危险品瞒报 (Concealment of Dangerous Goods)
寄件人为了节省运费或规避监管，将电池、易燃易爆化学品、压力容器等禁运物品伪报为普通生活用品（如“服装”、“日用品”）。
*   **风险**: 可能引发火灾、爆炸，威胁物流中转站及运输工具安全。
*   **识别特征**: 申报价值与重量不符，高频寄送小件包裹，寄件地址集中在化工园区或电子批发市场。

### 1.2 代收货款（COD）欺诈 (Cash on Delivery Fraud)
寄件人邮寄廉价、伪劣甚至空包裹，勾结或利用物流链路，在收件人签收并支付货款后迅速提取资金。
*   **风险**: 导致收件人经济损失，损害物流公司信誉。
*   **识别特征**: 拒收率极高，寄件人注册时间短，包裹申报价值远高于市场价。

### 1.3 跨境包裹申报价值异常 (Cross-border Value Discrepancy)
在跨境电商物流中，为了偷逃税款，故意低报商品价值（Under-declaration），或者为了骗取出口退税而高报价值（Over-declaration）。
*   **风险**: 违反海关法，导致罚款或没收，影响跨境物流清关效率。
*   **识别特征**: 商品名称与申报单价明显不匹配，同一批次包裹申报价值高度统一且接近免税阈值。

### 1.4 实名信息冒用与虚假地址 (Identity Theft & Fake Address)
寄件人或收件人使用虚假身份证信息或冒用他人身份进行寄递，并使用临时地址、偏远无主地址或多人共用地址作为中转。
*   **风险**: 用于违禁品走私、非法集资礼品发放等违法活动，难以追溯责任人。
*   **识别特征**: 同一身份证号关联大量不同收件人姓名，地址包含大量模糊描述或临时租借点（如“xx快递柜旁仓库”）。

## 2. 关键业务字段

| 字段名 | 说明 | 示例 |
|---|---|---|
| `sender_id` | 寄件人唯一标识 | USR_10001 |
| `receiver_name` | 收件人姓名 | 张三 |
| `receiver_phone` | 收件人电话 | 13800138000 |
| `shipment_type` | 运单类型 | 普快, 特快, 跨境, 代收货款 |
| `declared_value` | 申报价值 | 299.00 |
| `actual_weight` | 实际重量 (kg) | 1.5 |
| `item_category` | 物品分类 | 电子产品, 服装, 食品, 化学品 |
| `is_dangerous` | 是否标识为危险品 | 0 (否), 1 (是) |
| `cod_amount` | 代收货款金额 | 500.00 |
| `origin_address` | 寄件起始地址 | 广东省深圳市龙岗区... |
| `dest_address` | 寄件目的地址 | 北京市朝阳区... |
| `id_card_verified` | 寄件人实名核验状态 | 1 (已通过), 0 (未核验) |

---

## 3. 业务事件类型

| 事件类型 | 说明 |
|---|---|
| `shipment_create` | 运单创建（寄件触发） |
| `shipment_cancel` | 运单取消（异常撤回） |
| `shipment_receive` | 运单签收（收件/支付触发） |
| `id_verification` | 实名认证（账号注册/变更触发） |

## 4. 行业术语表

| 术语 | 英文 | 说明 |
|---|---|---|
| **面单** | Waybill | 贴在包裹上的运单详情。 |
| **代收货款** | COD (Cash on Delivery) | 快递公司代寄件人向收件人收取货款。 |
| **反向物流** | Reverse Logistics | 退货、换货等逆向流转过程。 |
| **转运中心** | Sorting Center | 对包裹进行集中分拣的大型中转节点。 |
| **申报价值** | Declared Value | 寄件人向物流公司声明的包裹内物品价值。 |
