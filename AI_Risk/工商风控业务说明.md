## 银行工商行业风控系统 — 业务说明

**业务边界**：信用卡 / 贷款 / 转账 / 登录 四大场景
**监管口径**：全面覆盖 NFRA（银保监）、PBOC（人民银行）、外管局
**更新日期**：2026-08-11

---

### 一、行业典型欺诈场景

| # | 欺诈场景 | 关联场景 | 典型手法 |
|---|---|---|---|
| F1 | **伪冒办卡 / 信用卡套现** | 信用卡 | 冒用他人身份申请信用卡；虚构经营场所骗领 POS 机，通过虚假交易套取授信额度；"养卡"中介反复套现、以卡还卡 |
| F2 | **骗贷（信贷欺诈）** | 贷款 | 伪造银行流水 / 收入证明 / 经营数据虚增还款能力；同一时期在多家机构申请贷款（多头借贷）；"中介代办"帮客户包装材料绕过风控 |
| F3 | **电信诈骗资金转移** | 转账 | 受害人被诱骗向诈骗账户转账；资金到账后秒级拆分至 N 张下级卡（"水房"洗钱模式）；多卡归集到同一收款账户 |
| F4 | **账户接管（ATO / 撞库）** | 登录 | 通过社工库/拖库获取密码撞库登录；更换设备后立即发起大额交易；使用代理 IP / Tor 规避地理风控；同一设备关联大量不同账户 |
| F5 | **内外部勾结 / 虚假资料** | 贷款 / 信用卡 | 银行内部人员协助客户伪造开户/贷款材料；关联企业间互相担保、隐藏实际控制人关系规避统一授信 |
| F6 | **洗钱 / 拆分交易** | 转账 | 将大额资金拆分为多笔低于 PBOC 大额报告阈值的交易（结构化交易 / "化整为零"）；通过多层账户嵌套转移资金，掩盖资金来源与去向；利用虚假贸易背景构造跨境支付 |
| F7 | **票据欺诈** | 贷款 / 转账 | 伪造或变造银行承兑汇票、商业承兑汇票；无真实贸易背景办理票据贴现（"贴现空转"）；票据中介非法倒票，利用空壳公司自开自贴套取银行资金 |
| F8 | **人户分离 / 账户租借** | 登录 / 转账 | 账户实际使用人与开户人不一致（"人户分离"）；个人出租、出借、出售银行卡供电信诈骗或洗钱团伙使用——"断卡行动"重点打击对象；对公账户被用于资金过渡后快速销户 |
| F9 | **非法集资 / 传销归集** | 转账 | 以高息理财、虚拟币、消费返利等名义吸收公众存款；大量分散账户向少数核心账户集中转账，呈现"金字塔"式资金归集模式；短期内涌入大量新开户并伴随小额入金 |
| F10 | **虚假按揭 / 联合骗贷** | 贷款 | 开发商与购房人串通虚构房产交易套取按揭贷款；虚高房产评估价值以获取超额授信；"零首付""首付贷"等违规操作，掩盖真实首付来源 |

### 二、关键业务字段（15 个）

| 序号 | 字段名 | 来源表 | 业务含义 |
|---|---|---|---|
| 1 | `user_id` | UserInfo | 用户唯一标识 |
| 2 | `id_card_hash` | UserInfo | 身份证号哈希，用于实名核验与黑名单匹配 |
| 3 | `kyc_level` | UserInfo | 客户尽职调查等级（L1-L5），决定业务权限上限 |
| 4 | `credit_score` | UserInfo | 行内信用评分，综合征信、交易、还款行为 |
| 5 | `card_type` | BankCard | 卡类型（借记卡/信用卡/Ⅱ类户），影响交易限额与场景准入 |
| 6 | `credit_limit` | BankCard | 信用卡/循环贷授信额度，超额需人工审批 |
| 7 | `amount` | Transaction | 交易金额（单笔），大额阈值参考 PBOC 大额交易报告标准 |
| 8 | `channel` | Transaction | 交易渠道（网银/手机银行/快捷支付/柜面），不同渠道风险权重不同 |
| 9 | `from_card` / `to_card` | Transaction | 付款卡与收款卡，用于多卡归集检测与黑卡拦截 |
| 10 | `term_months` + `purpose` | LoanApplication | 贷款期限与资金用途，用于用途真实性校验 |
| 11 | `debt_ratio` | LoanApplication | 月负债/收入比，衡量还款能力与过度授信 |
| 12 | `device_id` | DeviceFingerprint | 设备指纹，用于新设备识别、设备多人共用检测 |
| 13 | `ip` + `is_proxy` | LoginLog / IpGeoLocation | 登录 IP 及代理判定，命中代理库 / Tor 出口则标记 |
| 14 | `geo` | LoginLog / Transaction | 登录地 / 交易地经纬度或城市编码，用于异地操作识别 |
| 15 | `type` + `value` | BlacklistExtra | 黑名单条目类型（身份证/卡号/IP/设备指纹）及命中值 |

### 三、业务事件类型（6 类）

| # | 事件类型 | 触发时机 | 关联表 | 典型规则示例 |
|---|---|---|---|---|
| E1 | **注册/开户事件** | 用户首次提交身份信息 | UserInfo | KYC 等级校验、身份黑名单匹配 |
| E2 | **登录事件** | 每次登录鉴权 | LoginLog + DeviceFingerprint | 新设备登录、异地登录、代理 IP 登录 → 标记/加强验证 |
| E3 | **转账/支付事件** | 资金从 A 卡到 B 卡 | Transaction + BankCard | 异地大额转账（R001）、凌晨密集操作（R002）、多卡归集（R008）、黑卡拦截（R030） |
| E4 | **贷款申请事件** | 提交贷款申请 | LoanApplication + UserInfo | 信贷申请突击（R012）、收入负债比异常、用途不合规 |
| E5 | **绑卡/换卡事件** | 用户绑定或更换银行卡 | BankCard + UserInfo | 新绑卡短时间内大额交易、绑卡 IP 与开户地不一致 |
| E6 | **大额/可疑交易上报** | PBOC 阈值触发 | Transaction | 单笔/累计超限自动生成大额交易报告或可疑交易报告（STR） |

### 四、行业术语表（8 条）

| 术语 | 英文 | 释义 |
|---|---|---|
| **KYC / CDD** | Know Your Customer / Customer Due Diligence | 客户尽职调查，银行在建立业务关系时必须完成的身份识别与风险评估流程。央行要求至少包含：身份识别、风险等级划分、持续监控 |
| **统一授信管理** | Unified Credit Management | 银行对同一客户（含关联方）的所有表内外授信合并计算额度、集中管控，防范多头过度授信 |
| **贷款五级分类** | Five-Category Loan Classification | 正常 / 关注 / 次级 / 可疑 / 损失，NFRA 要求银行按风险程度对信贷资产进行分类和拨备 |
| **大额交易报告 / 可疑交易报告** | Large Transaction Report / STR | PBOC 反洗钱核心报送机制：大额（自然人单笔 ≥20 万 / 法人 ≥200 万）必报，可疑按模型判定后上报中国反洗钱监测分析中心 |
| **多头借贷** | Multi-platform Lending | 借款人在短期内向多家金融机构申请贷款，是信用风险与欺诈风险的强信号 |
| **账户接管（ATO）** | Account Takeover | 攻击者通过撞库、钓鱼等方式获取用户凭证后控制账户，典型特征是设备/地点突变 + 后续高风险操作 |
| **受益所有人（UBO）** | Ultimate Beneficial Owner | 最终拥有或实际控制客户的自然人，央行要求穿透识别持股 ≥25% 或实际控制公司的自然人 |
| **受托支付** | Entrusted Payment | 贷款资金由银行直接支付给借款人的交易对手方而非借款人本人，NFRA 规定特定用途贷款必须执行受托支付 |

### 五、风控规则清单（31 条）

#### 登录场景

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R003 | 异地登录 | 登录城市 != 历史常用城市 + 两次登录间隔 < 1 小时（物理不可达） | 中 | 加强验证 |
| R004 | 短时多地登录 | 1 小时内 ≥ 2 个不同城市登录记录 | 高 | 人工审核 |
| R006 | 频繁登录失败 | 5 分钟内 ≥ 5 次密码错误 | 中 | 锁定 30 分钟 |
| R011 | 深夜异常登录 | 0:00–5:00 登录 + 用户历史无此时段活动记录 | 低 | 标记 |
| R029 | 短时间内频繁改密 | 24h 内修改密码 ≥ 2 次 | 中 | 加强验证 |

#### 转账 / 支付场景

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R001 | 异地大额转账 | 登录城市 != 常用城市 + 单笔 ≥ 5 万 | 极高 | 拒绝 |
| R002 | 凌晨密集操作 | 0:00–5:00 + 1 小时内 ≥ 3 笔交易 | 高 | 人工审核 |
| R005 | 新设备大额 | 设备首次使用 < 7 天 + 单笔 ≥ 3 万 | 高 | 人工审核 |
| R007 | 小额测试后大额 | 10 分钟内先有小额（≤ 10 元）后有同收款卡大额（≥ 1 万） | 极高 | 拒绝 |
| R008 | 多卡归集 | 1 小时内 ≥ 3 张不同付款卡转入同一收款卡 | 极高 | 拒绝 |
| R009 | 新绑卡立即大额 | 绑卡后 24h 内单笔 ≥ 5000 | 高 | 人工审核 |
| R010 | 向新收款人大额转账 | 收款卡首次出现在用户交易历史 + 单笔 ≥ 1 万 | 中 | 加强验证 |
| R031 | 收款账户高风险地区 | 收款卡归属地命中高危地域名单 + 单笔 ≥ 5000 | 高 | 人工审核 |
| R030 | 黑卡拦截 | 收款卡号命中黑名单 | 极高 | 拒绝 |

#### 贷款场景

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R012 | 信贷申请突击 | 当月已申请 ≥ 3 家不同机构贷款 | 高 | 人工审核 |
| R013 | 收入负债比超限 | `debt_ratio` > 70% + 新申请金额 > 月收入 × 12 | 极高 | 拒绝 |
| R014 | 贷款用途违规 | `purpose` 命中禁入领域（投资/炒股/虚拟币/赌博等） | 极高 | 拒绝 |
| R015 | 申请信息频繁修改 | 审批期间修改关键字段（金额/期限/用途）≥ 3 次 | 中 | 标记 |
| R016 | 短时多笔申请 | 同一用户 24h 内提交 ≥ 2 笔不同贷款申请 | 高 | 人工审核 |

#### 信用卡场景

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R017 | 新卡大额消费 | 开卡 < 30 天 + 单笔消费 ≥ 授信额度 80% | 高 | 人工审核 |
| R019 | 疑似套现 | 多笔整数金额 + 非营业时间（22:00–08:00）+ 同一商户 + 当日累计 ≥ 授信额度 60% | 高 | 人工审核 |
| R020 | 异地刷卡 | 交易城市 != 登录城市 + 单笔 ≥ 5000 | 中 | 加强验证 |
| R021 | 频繁最低还款 | 连续 ≥ 6 期仅还最低还款额 + 额度使用率 > 90% | 中 | 标记 + 降额 |

#### 设备 / 网络环境

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R018 | 设备多人共用 | 同一 `device_id` 关联 ≥ 5 个不同 `user_id` | 中 | 标记 |
| R022 | 设备指纹异常 | 设备信息高频变化（模拟器/越狱/改机特征） | 中 | 标记 |
| R023 | Root / 越狱设备 | 设备检出 root 或越狱 + 发起交易请求 | 高 | 拒绝 |
| R025 | IP 代理 / 秒拨 | 登录 IP 命中代理库 / Tor 出口节点 | 中 | 标记 |
| R026 | IP 频繁切换 | 同一会话内 IP 所属城市变化 ≥ 2 次 | 中 | 标记 |

#### 账户行为

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 |
|---|---|---|---|---|
| R024 | 休眠账户突然活跃 | 连续 ≥ 90 天无交易 + 首笔交易 ≥ 1 万 | 高 | 人工审核 |
| R027 | 信息变更后大额 | 修改手机号/预留信息后 1h 内发起 ≥ 5000 交易 | 极高 | 拒绝 |
