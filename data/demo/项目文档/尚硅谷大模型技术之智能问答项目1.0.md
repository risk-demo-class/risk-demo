# 智能问答项目实战（演示项目文档）

## 项目背景

本项目基于 RAG（检索增强生成）架构，搭建一个面向教育培训场景的智能问答系统：
将课程讲义、项目文档与题库导入向量知识库，用户提问时检索相关片段并生成带引用的回答。

## 系统架构

项目分为四层：

| 层级 | 说明 | 关键技术 |
| --- | --- | --- |
| 导入层 | 文档解析、切分、向量化、入库 | docx/md 解析、BGE-M3、Milvus |
| 查询层 | 意图识别、多路检索、融合重排 | LangGraph、RRF、Rerank |
| Web 层 | 上传、问答、流式输出 | FastAPI、SSE |
| 存储层 | 向量、对象、历史 | Milvus、MinIO、MongoDB |

## 导入流程

1. 上传课程资料 / 项目文档 / 题库文件。
2. 文档转 Markdown，处理图片。
3. 按标题切分文档，识别课程名、项目名、章节名等教育元数据。
4. 生成稠密与稀疏向量，写入 Milvus。
5. 课程介绍与题库走专用解析入库流程。

## 查询流程

1. 分析用户意图（课程介绍 / 文档检索 / 题目检索 / 知识问答）。
2. 对齐课程 / 项目 / 题库实体。
3. 多路检索（课程 / 文档 / HyDE / 题目 / 网络搜索）。
4. RRF 融合 + Rerank 重排。
5. 流式生成答案并返回引用信息。

## 部署步骤

1. 准备 Milvus、MinIO、MongoDB 与 LLM API。
2. 复制 .env.example 为 .env 并填写配置。
3. 安装依赖并启动导入服务（8000 端口）与查询服务（8001 端口）。
4. 先导入课程介绍、题库，再导入课程文档与项目文档。
5. 打开聊天页面体验课程检索、文档检索、题目检索与知识问答。
