# 教育数据目录

本目录用于存放教育知识库的原始资料。

## data/demo（演示数据）

开箱即用的演示数据，无需外部大文件即可体验完整导入流程：

- `课程介绍.md`：课程系列与课程明细
- `题目资料.md`：题库与题目（题型 / 题干 / 选项 / 答案 / 解析）
- `课程文档/`：课程讲义（Markdown 演示版）
- `项目文档/`：项目实战文档（Markdown 演示版）
