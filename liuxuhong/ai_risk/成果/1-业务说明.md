# 教育行业风控系统业务说明

## 1. 行业特征（与电商差异）

在线教育平台的核心业务链路是「课程浏览 → 报名下单 → 支付 → 学习 → 完课/退费」，不同于电商的「下单 → 支付 → 发货 → 物流 → 收货 → 售后」。

主要差异：

- **商品是虚拟服务**：课程无实物库存，无物流配送，履约靠平台监督学习进度
- **退费规则复杂**：部分学时消耗后按比例退费，"0学时全额退"是政策要求也是欺诈高发区
- **用户身份多样**：学生、家长、老师三种角色，学号、身份证号等 PII 贯穿全流程
- **设备指纹关键**：假学员代理通过共享设备批量注册+报名+套取新客优惠
- **监管强约束**：教育"双减"政策、预付费资金监管、《个人信息保护法》对学生信息有特殊保护要求

## 2. 典型欺诈场景（8 种）

| 场景 | 行为描述 | 典型风险信号 |
| --- | --- | --- |
| 刷单式报名 | 同一课程短期内被大量新账号报名，套取平台新客补贴或刷课程销量排名 | 同课程7天内>=3个新账号报名 |
| 0学时退费 | 报名后未上课或仅看几分钟就申请全额退款，利用"7天无理由"政策薅羊毛 | 学习时长<5分钟 + 申请退费 |
| 大额连报 | 短时间内报名多门高价课程，可能使用盗刷信用卡付款后退款套现 | 1小时内订单金额>30000元 |
| 假学员代理 | 同一设备批量注册学员账号，冒充不同用户享受新客优惠 | 同设备指纹关联>=5个学员账号 |
| 退费连环 | 用户频繁报名又退费，在不同课程之间反复操作 | 90天内退款>=3次 + 累计金额>10000元 |
| 直播打赏洗钱 | 通过打赏功能将非法资金转化为平台余额，再提现或购买课程变现 | 单场打赏>5000元 + 账号注册<30天 |
| 学历/身份造假 | 使用虚假身份信息进行学历认证，冒充在校学生套取学生优惠 | 身份信息与第三方认证接口不匹配 |
| 账号盗用与冒名 | 盗用已认证学员账号报课、退费、转移余额 | 登录设备突变 + 退费收款账户更换 |

## 3. 关键业务字段（11 个）

| 字段 | 说明 |
| --- | --- |
| `user_id` / `student_id` | 平台用户ID + 学号，双重身份标识 |
| `role` | 用户角色: 学生/家长/老师，不同角色对应不同风控策略 |
| `real_name_status` | 实名认证状态: 未认证/已认证/认证失败 |
| `course_id` / `category` | 课程唯一标识 + 类别(学科辅导/兴趣培养/职业技能/语言学习/考级考证) |
| `order_id` / `total_amount` | 报名订单ID + 实付金额 |
| `study_goal` | 用户学习目标，文本字段可分析信息量(填假目标可能是风险信号) |
| `expected_finish_days` | 预期完成天数，与价格对比可发现异常 |
| `total_minutes` / `completion_rate` | 学习进度核心指标(累计学习时长/完课率) |
| `refund_id` / `study_minutes_before_refund` | 退费申请ID + 退费前已学习时长(分钟) |
| `device_id` / `fingerprint` | 设备指纹，用于识别多账号关联 |
| `ip` | 用户IP地址，识别地理位置异常 |

## 4. 业务事件类型（4 种）

| 事件类型 | 触发时机 | 风控关注点 |
| --- | --- | --- |
| 课程报名 | 用户提交报名订单 | 刷单报名、新用户大额、多设备关联 |
| 退费申请 | 用户发起退费请求 | 0学时退费、高频退费、连环退费 |
| 学历认证 | 用户提交学历/身份认证 | 虚假认证材料、身份冒用 |
| 直播打赏 | 用户在直播中打赏 | 大额异常打赏、新账号频繁打赏、洗钱嫌疑 |

## 5. 行业术语表（8 个）

| 术语 | 含义 |
| --- | --- |
| 完课率 | 用户实际完成课程进度的比例(0-1)，核心教学质量指标 |
| 0学时退费 | 未产生有效学习时长即申请退费，政策保护消费者但易被滥用 |
| 连报 | 短时间内连续报名多门课程的行为模式 |
| 设备指纹 | 基于浏览器/App特征的唯一设备标识，用于跨账号关联分析 |
| 学号 | 教育机构分配的唯一学生标识，与user_id形成双ID体系 |
| 假学员代理 | 利用批量虚假身份注册、报名、套取优惠的灰产模式 |
| 预付费 | 教育行业常见付费模式，先付费后上课，存在资金安全风险 |
| 直播打赏 | 教育直播中的打赏功能，金额异常可能是洗钱通道 |

## 6. 国内监管要求

- **实名制与教育合规**：学生实名认证、学籍信息核验，"双减"政策禁止义务教育阶段学科类校外培训收费超纲
- **个人信息保护（《个人信息保护法》）**：学生学号、身份证号、学习轨迹属于敏感个人信息，须单独同意、最小必要、目的限定
- **数据安全（《数据安全法》《网络安全法》）**：未成年人个人信息处理须取得监护人同意，日志留存不少于6个月
- **预付费资金监管**：校外培训机构预收费须全额纳入监管，防止卷款跑路，风控需识别异常退费集中爆发
- **消费者保护**：退费规则须明示，不得设置不合理退费门槛；风控处置不能无依据限制正常学员权益
