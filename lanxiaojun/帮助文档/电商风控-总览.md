```
"""系统功能概述"""
1. 实时决策 — 对每一笔下单/支付/售后/投诉请求，经过 7步流水线（事件→特征→规则→XGBoost→评分→落库），在几百毫秒内输出"通过/标记/人工审核/拒绝"四档决策

2. 规则+AI 双保险 — 规则引擎（30 条预置规则，JSON 条件求值）和 XGBoost模型各自打分后加权融合，同时一票否决机制确保极高风险规则不被 AI 低分推翻
  
3. 黑名单前置拦截 — 在进引擎之前先查用户/地址/手机号三种黑名单，命中就直接拒绝，不走后续流程
  
4. AI 分析助手 — 接入阿里云千问大模型，分析师可以用自然语言查案件、看画像、做统计，不用写 SQL
  
5. 自动监控 — 后台定时检查待审案件是否超时、规则命中率是否异常、撞黑比例是否过高，发现问题自动写告警
```
