## 一、行业典型欺诈场景（6 种，含真实案例背景）

### 场景 1：机票"占座"囤票与退改签套利（黄牛产业链）
黑产利用航司"先占座后付款"或"低价舱位免费退改"规则，用大量账号锁定热门航线/节假日机票，加价转卖给真实旅客，或在价格波动时反复退改套利。
- **典型套路**：同一设备/支付账号 1 小时内预订 N 张同航班机票；深夜（0-5 点）集中操作；行程距出发 < 7 天的"急单"。
- **监管背景**：民航局实名制要求"票、证、人一致"，但占座环节只登记不付款，实名核验存在空窗。
- **风险后果**：挤占真实运力、扰乱价格体系、平台被航司追责（NOSHOW 率异常）。

### 场景 2：酒店"到店无房 + 拒退"与刷单炒信
- **到店无房**：代理超售酒店房间，用户到店后无房，平台赔付压力巨大（真实案例：2023-2024 年多起"OTA 订房到店无房"舆情事件）。
- **刷单炒信**：商家（酒店/旅行社）自买自评，用新注册账号 + 虚假订单抬高销量排名。
- **风险信号**：同一收货/联系手机号关联多个账号；新账号 7 天内高频下单同一酒店；入住日期临近（当天/次日）大量下单。

### 场景 3：签证材料造假与"拒签退款"纠纷
- 申请人伪造流水/在职证明骗取签证；签证代理（黑中介）批量代填、材料批量雷同。
- **风险后果**：拒签后平台/代理退款纠纷；签证中心对平台产生信任风险（真实背景：多国签证中心对"高频送签异常"机构实施熔断）。
- **风险信号**：90 天内多次申请不同国家签证；同一用户短期内签证被拒 >= 2 次；多人共用同一送签材料模板。

### 场景 4：账户盗用与"黑卡"买票（支付欺诈）
- 黑产用盗来的信用卡/他人账户在平台下单买机票/酒店，收货后变现（真实背景：OTA 是信用卡盗刷重灾区，国际卡组织对盗刷率高的商户有惩罚性费率）。
- **风险信号**：新设备登录 + 大额订单；乘客证件号与支付账户实名不一致；下单后立即改签/退票套现。

### 场景 5：跟团游"低价团"与购物返佣套利
- 黑产旅行社用超低价团（低于成本价）吸引报名，实际靠购物返佣/自费项目盈利，游客体验差导致平台投诉与监管处罚（《旅游法》第 35 条禁止"不合理低价游"）。
- **风险信号**：团费显著低于市场价 + 行程天数短；同一旅行社短时间内大量同质订单。

### 场景 6：航延险/退改险"薅羊毛"骗保
- 利用天气预测 + 多账号批量购买航班延误险，航班取消后集中理赔（真实案例：2019 年南京李某利用航班延误险骗保 300 余万被刑拘——"航延险"是旅游平台公认的高风险险种）。
- **风险信号**：同一设备/证件号关联大量订单；单用户高频购买保险；投保集中在恶劣天气航线的多个航班。

## 四、行业术语表（8 个）

| 术语 | 解释 |
|---|---|
| **OTA** | Online Travel Agency，在线旅游平台（携程/飞猪等） |
| **占座** | 先锁定航班座位/低价舱位暂不付款，伺机转卖或退改 |
| **NOSHOW** | 已订票/订房但未在起飞前/入住日取消的"爽约"行为，航司/酒店会追责平台 |
| **拒签** | 签证申请被使领馆驳回，通常伴随费用损失与退款纠纷 |
| **黑卡** | 盗用他人信用卡/银行卡信息进行支付的行为 |
| **退改签** | 机票/酒店的退票、改期、签转操作，是套利与纠纷高发环节 |
| **不合理低价游** | 低于成本价招徕游客、靠购物返佣牟利的旅游产品（《旅游法》第 35 条禁止） |
| **航延险** | 航班延误险，曾被黑产批量购买骗保（2019 年南京案） |

## 五、监管要求（国内）

1. **实名制**：机票"票、证、人"一致（民航局）；酒店住宿实名登记（《旅馆业治安管理办法》）；平台需核验用户身份。
2. **《在线旅游经营服务管理暂行规定》**（文旅部，2020.10.1 施行）：OTA 平台需对经营者资质、信息真实性负责，不得虚标价格、虚假预订。
3. **《旅游法》**：禁止不合理低价游（第 35 条）；旅行社需具备经营资质。
4. **《个人信息保护法》**：证件号等敏感个人信息需单独同意 + 加密存储（本项目对证件号做脱敏/哈希处理）。
