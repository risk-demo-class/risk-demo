# 录屏前检查清单（recording-checklist）

> 用途：开始录屏前逐项核对环境、窗口、数据、隐私、音频与时间控制。完整讲解见 `docs/demo-script.md`。

## 1. 环境与数据

- [ ] 专用 MySQL 容器已启动：`docker ps` 可见 `ai-risk-goal3-mysql`（映射 `127.0.0.1:33307`），库 `bank_risk_test` 存在 17 张表。
- [ ] 应用已启动：`http://127.0.0.1:8000/` 返回 200，`/docs` 可访问。
- [ ] XGBoost 模型已加载：`app/engine/xgb_model.json` 存在；风险检查结果页能看到模型概率（非「模型未加载」）。
- [ ] 演示样例数据存在：`DEMO_LOGIN_006`、`DEMO_TXN_001/003/008/017`、`DEMO_LOAN_003`、`DEMO_CARD_003` 均可用（四事件 smoke 全部 200）。
- [ ] 评估与案件有数据：总览页指标非全 0，案件页有待审或已审记录（可用 `docs/demo-script.md` 样例先行跑一遍造数据）。

## 2. 窗口与显示

- [ ] 浏览器窗口至少 1440×900；若用移动视口演示，用浏览器 DevTools 设备模式切 390×844。
- [ ] 隐藏无关书签栏/扩展/通知；无其他应用窗口遮挡。
- [ ] 关闭可能弹出安全提示的代理/VPN；确认局域网演示不需要时断开外部网络依赖（仅 CDN 静态资源需联网）。
- [ ] 页面无横向滚动条；关键页面（总览、风险检查、案件、评估、规则、黑名单）无遮挡。
- [ ] 预先打开全部 6 个工作台页面一次，避免录制中出现首次加载的空白态。

## 3. 数据库与造数

- [ ] 只使用 `bank_risk_test`（教学库）；不连接、不展示任何真实数据库。
- [ ] 若重置数据：`scripts\init_db.py --db bank_risk_test --reset --yes` → `scripts\gen_business_data.py --count 2400 --seed 20260812` → `scripts\gen_train_dataset.py --count 2000 --seed 20260812 --clean` → `scripts\train_xgb_model.py` → 重启应用。
- [ ] 确认录屏中展示的卡号/证件/IP 均为虚构或摘要（黑名单列表已自动脱敏）。

## 4. 隐私检查

- [ ] 不打开 `.env`、日志、数据库转储或任何含凭据的文件。
- [ ] 不展示本机用户名、完整路径（如 `C:\Users\...`）、GitHub 账户敏感信息或个人文件。
- [ ] 终端窗口不残留 `.env` 内容、API key 或密码；如已输入先清屏。
- [ ] 截图/录屏中不出现浏览器保存的密码或自动填充建议。

## 5. 音频与口播

- [ ] 麦克风正常；录制前试录 10 秒并回放（回声/底噪/音量）。
- [ ] 旁白语速适中，关键结论句（如「教学数据不代表真实能力」）放慢强调。
- [ ] 演示脚本已通读一遍；把「用户」「来源」等词改成自己顺口的口吻。

## 6. 时间控制

- [ ] 总时长控制在 5–8 分钟：业务 1 分钟、风险检查+案件/评估 2 分钟、XGBoost 1 分钟、重点规则 2 分钟、Vibe Coding 复盘 1 分钟。
- [ ] 每段操作后留 2–3 秒静默让画面稳定，不要边操作边读脚本。
- [ ] 一次录坏重录本段，不必重录全部；最后整体拼接。

## 7. 失败回退

| 问题 | 处理 |
|---|---|
| 风险检查返回 400/403 | 核对 `event_type` 与 `source_id` 配对、`user_id` 归属（见 `docs/demo-script.md` 样例速查表） |
| 模型「未加载」 | 确认 `xgb_model.json` 存在并重启应用；不行则执行训练脚本 |
| 页面空白/接口错误 | 看服务端日志与浏览器控制台；确认 MySQL 连接与 `.env` |
| 总览无数据 | 按第 3 节重置并重跑造数/训练 |
| 录音中断 | 暂停该段，重录该段后拼接；脚本每段可独立成段 |

## 8. 录制完成

- [ ] 导出视频后整体看一遍，确认没有露出凭据/本机隐私。
- [ ] 更新 `docs/final-verification.md` 中“视频录制状态”说明（保持“由用户按脚本录制”，不声称自动完成）。
