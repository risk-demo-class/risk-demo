# 银行业风控系统 · 业务说明

> 本文档为 `Bank-Risk` 项目交付物，定义银行风控系统的典型欺诈场景、关键业务字段、业务事件类型与行业术语，并严格对齐基线项目 `AI_Risk` 的"可复用模块 / 必须自建模块"边界划分。与电商风控（偏消费行为异常：订单金额、退款率、收货地址、物流投诉）不同，银行风控聚焦**资金流转安全、信贷敞口管控、账户安全防护与监管报送合规**。

---

## 一、典型欺诈场景

| 场景 | 业务痛点 | 风险特征 | 处置要求 |
| --- | --- | --- | --- |
| 信用卡伪冒交易 | 卡片信息泄露后被异地、短时间内高频盗刷 | 交易地点突变、商户类型异常、交易金额聚集 | 实时拦截 + 卡冻结 + 报文上报 |
| 多头借贷骗贷 | 借款人短期内跨多家机构重复申贷，以贷养贷最终违约 | 征信查询次数激增、收入负债比失真、申贷机构数超阈 | 贷前拒绝 / 降额 + 信贷敞口预警 |
| 账户盗用与洗钱转账 | 账户被控后分散转入、集中转出，规避大额监测 | 设备/IP 突变、资金快进快出、交易对手分散归集 | 一票否决阻断 + 可疑交易报送 AML |
| 电信诈骗资金链（受害人被诱导转账） | 客户被"客服/杀猪盘/投资"话术诱导，向涉诈账户大额实时转账，资金极难追回 | 转账对手命中涉案黑名单、收款为"对公洗钱通道"、通话异常伴随转账、非习惯时段大额 | 实时拦截 + 保护性止付 + 移送反诈联席办（人民银行"资金链"治理） |
| 经营性贷款资金挪用 / 借名骗贷 | 经营贷、消费贷违规流入楼市股市，或借名贷款伪造资料骗取信贷资金 | 资金回流股东/关联方、贷款用途与经营背离、资料造假、抵押物不实 | 贷前拒贷 + 贷后资金流向监测 + 监管报送 |

## 二、关键业务字段（≥10，覆盖用户/卡片/交易/贷款/登录/设备/IP 地理）

> 字段归属标注：`[自建]` = 必须自建（替换 `models_business.py` / 扩展 `RiskCheckRequest.event_data` / 重写 `feature.py`）；`[复用]` = 沿用基线风控核心表（`models_risk.py`）。

| # | 字段 | 维度 | 归属 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | `customer_id` 客户号 | 用户 | `[自建]` | 银行核心客户唯一标识，关联 KYC 档案 |
| 2 | `id_type` / `id_no` 证件类型/号 | 用户 | `[自建]` | 实名认证与反洗钱身份识别必备 |
| 3 | `card_no` / `card_bin` 卡号/卡 BIN | 卡片 | `[自建]` | 卡片伪冒识别、BIN 归属地与交易地比对 |
| 4 | `txn_amt` / `txn_channel` 交易金额/渠道 | 交易 | `[自建]` | 资金流转金额与渠道（ATM/Pos/网银/手机银行） |
| 5 | `counterparty_acct` 交易对手账户 | 交易 | `[自建]` | 洗钱资金分散归集与闭环识别 |
| 6 | `loan_apply_amt` / `loan_term` 申贷金额/期限 | 贷款申请 | `[自建]` | 多头借贷与收入负债比测算 |
| 7 | `credit_query_cnt` 征信查询次数 | 贷款申请 | `[自建]` | 近 N 日机构查询数，多头借贷核心特征 |
| 8 | `login_type` / `login_result` 登录方式/结果 | 登录 | `[自建]` | 密码/指纹/人脸 + 成功失败，账户盗用识别 |
| 9 | `device_fingerprint` 设备指纹 | 设备 | `[自建]` | 设备突变识别盗用，特征工程输入 |
| 10 | `ip_addr` / `ip_location` IP/地理 | IP地理 | `[自建]` | 登录/交易地理与常用地偏离检测 |
| 11 | `gps_location` 经纬度 | IP地理 | `[自建]` | 交易定位与卡片 BIN 地一致性校验 |
| 12 | `risk_level` / `risk_score` 风险等级/分 | 风控 | `[复用]` | 双轨融合输出，规则分 + XGBoost 校准 |

## 三、业务事件类型（≥3，对齐 `schemas.py` 的 `event_type` 枚举"必须自建"替换）

> **行业真实痛点核验**：以下事件类型均对应银行真实高频风险与监管报送动作，并非电商枚举的简单平移——
> - `transfer`：电信诈骗"资金链"治理是人民银行核心监管动作，受害人被诱导实时转账、涉诈资金极难追回，须实时拦截+保护性止付+移送反诈联席办；
> - `loan_apply`：借名骗贷、经营贷挪用等案件频发（单案可骗贷逾亿元），贷前审查与资金流向监测为监管重点；
> - `login` / `card_txn`：账户盗用、伪冒交易的实时识别是反欺诈系统 7×24 监测主战场；
> - `repay`：贷后回款异常（逾期、代偿、资金回流）关联信贷敞口与不良率。
> 基线电商枚举（下单/支付/售后申请/物流投诉）与此差异显著，故需整体替换。

基线电商枚举（下单/支付/售后申请/物流投诉）→ 银行替换为：

| event_type | 说明 | 对应决策阈值分组（`RISK_EVENT_THRESHOLDS`） | 行业真实痛点 |
| --- | --- | --- | --- |
| `transfer` 转账交易 | 同行/跨行资金转移，电诈资金链与洗钱高发 | 按金额/对手数/涉诈黑名单拆阈 | 受害人被诱导大额实时转账、对公账户成洗钱通道，须拦截+保护性止付 |
| `loan_apply` 贷款申请 | 贷前审查入口，多头借贷与借名骗贷识别 | 征信查询频次/收入负债比阈 | 经营贷挪用、资料造假骗贷，监管严查过度授信 |
| `login` 登录事件 | 账户安全防护，设备/IP 突变 | 失败次数/地理偏离阈 | 账户盗用、盗号后改绑，反欺诈系统主战场 |
| `card_txn` 卡片交易 | 刷卡/无卡消费，伪冒识别 | 地域/频次/商户类型阈 | 卡片信息泄露后异地高频盗刷，须实时拦截 |
| `repay` 还款 | 贷后回款异常监控 | 逾期/代偿/资金回流阈 | 贷后不良与信贷敞口预警 |

## 四、行业术语表（≥5）

| 术语 | 释义 |
| --- | --- |
| **KYC**（客户身份识别） | 开户及持续尽职调查，核验客户真实身份与风险状况，反洗钱第一道防线 |
| **贷前审查** | 放款前对借款人资质、征信、还款能力的审核，拦截多头借贷与骗贷 |
| **设备指纹** | 采集终端软硬件特征生成唯一标识，用于识别账户盗用与异地登录 |
| **多头借贷** | 借款人短期内向多家机构重复申贷，征信查询激增、违约率高 |
| **反洗钱 AML** | 识别并报送大额与可疑交易，阻断资金分散归集、快进快出等洗钱链路 |
| **一票否决** | 命中"极高"风险规则即强制拒绝，机器学习结果不得推翻（基线复用机制） |

## 五、与基线项目模块边界对齐

**✅ 可复用模块（直接迁移/适配，不改架构）**
- `app/engine/decision.py`：7 步决策流水线（校验→事件→特征→快照→规则→决策→持久化）
- `app/engine/rule.py`：规则匹配引擎 + `risk_level↔risk_score` 互验
- 双轨融合：规则分（0–100）+ XGBoost 概率 sigmoid 校准（`risk_score=100*(1-exp(-k*prob))`，k=3）
- 一票否决：命中"极高"规则即强制拒绝，不被 ML 推翻
- 风控核心表（`models_risk.py`）：RiskRule / RiskEvent / RiskFeature / RiskAssessment / RiskCase / RiskBlacklist / RiskUserProfile / RiskActionLog / RiskAlert
- `RISK_EVENT_THRESHOLDS` 按 `event_type` 拆阈、`RISK_LEVEL_SCORE_MAP` 4 档映射（`config.py`）
- `app/routers` REST 模式、`app/service` 分层、`app/scheduler.py` 调度、`app/agent` Agent 辅助分析

**🆕 必须自建模块（银行场景专属，需重写）**
- `app/models_business.py`（电商 17 表）→ 银行核心表：customer / account / card / transaction / loan_application / login_event
- `app/engine/feature.py`（25 维电商特征）→ 银行特征（客户/卡片/交易/贷款/登录/设备/IP 地理）
- `app/schemas.py` 的 `event_type` 枚举 → 转账/贷款申请/登录/卡片交易/还款
- `RiskCheckRequest.event_data` → 扩展卡片号、设备指纹、IP、GPS、登录方式等银行字段
- 监管合规约束：数据采集最小化、KYC、AML 大额/可疑交易上报、个人金融信息保护

## 六、国内监管合规备注

- **数据采集最小化与告知同意**：依据《个人信息保护法》《GB/T 35273 个人信息安全规范》，采集证件、设备指纹、位置等须明示告知并取得同意，遵循最小必要原则。
- **个人金融信息保护**：遵循央行 **JR/T 0171-2020《个人金融信息保护技术规范》**，对 C3 类敏感信息（账户、卡号、生物特征）加密存储与脱敏展示。
- **风险评估可解释与模型可回溯**：风控决策须可解释以接受监管审计，规则与模型版本、阈值、特征需留痕可回溯。
- **反洗钱报送**：依据《反洗钱法》及《金融机构大额交易和可疑交易报告管理办法》，对大额交易与可疑交易（分散转入集中转出、快进快出等）及时上报中国反洗钱监测分析中心。
- **贷前审查合规**：贷款审批遵守银保监会/国家金融监督管理总局审慎监管要求，征信查询须获授权，防范过度授信与多头借贷风险。
