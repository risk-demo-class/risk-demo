# 业务数据管理模块

打开 Web 系统后，进入左侧“业务数据管理”。

可维护的数据：

- 供应商：资质状态、资质到期日、风险等级。
- 设备：运行状态、保养到期日、校准到期日。
- 工单：计划数量、完工数量、工单状态。
- 过程质检：实测值、检验结果。
- 发运：放行质量、放行人。

操作顺序：

1. 选择业务数据类型。
2. 找到记录并点击“编辑”。
3. 修改允许维护的字段。
4. 保持“保存后自动重新执行关联工单风险检查”勾选。
5. 点击“保存修改”。
6. 到“风险事件”“案件管理”“评估历史”查看新产生的检查结果。

说明：编辑结果会真实写入 MySQL 的 `manufacturing_risk` 数据库。再次运行 `uv run python scripts\init_db.py` 会重建演示数据并覆盖手工修改。
