# 旅游风控（OTA）业务说明

> 行业：在线旅游 OTA（Online Travel Agency）
> 范围：机票 / 酒店 / 签证 / 跟团游 四大预订场景
> 基线：AI_Risk 电商风控系统（复用风控核心，重写业务层）
> 任务：任务书「场景 A 旅游风控」· 任务 1 交付物

---

## 1. 业务边界

用户在 OTA 平台（对标携程 / 飞猪 / 去哪儿）完成机票、酒店、签证、跟团游的**搜索 → 下单预订 → 支付 → 出票/确认 → 出行/入住 → 退改签/售后**全流程。风控聚焦"预订到出行前"的关键环节，重点拦截：黄牛囤票、签证欺诈、退改签滥用、账户盗用、批量注册薅羊毛、大额代付资金异常。

## 2. 业务事件类型（4 种）

| 事件类型 | source_id 对应实体 | 说明 |
|---|---|---|
| 机票预订 | order_id | 订单主表(order_type=机票) + booking_flight 明细 |
| 酒店预订 | order_id | 订单主表(order_type=酒店) + booking_hotel 明细 |
| 签证申请 | visa_id | 签证申请表，无订单关联，只算用户特征 |
| 跟团游预订 | order_id | 订单主表(order_type=跟团游)，金额大、决策要求高 |

> 设计取舍：退改签不单独设事件类型，作为订单的"售后行为"统计进用户特征（退改次数/退改率），控制个人工作量且不破坏 4 事件契约。

## 3. 典型欺诈场景（6 种，★为核心场景）

### ★3.1 黄牛囤票 / 占座倒卖
- 同一支付账号 / 设备 **1 小时内预订 ≥5 张同航班 / 同酒店**（典型 R 规则）
- 热门节假日占座不支付（机票占位），转手高价倒卖
- 特征线索：预订频率、同航班预订数、支付失败率、距出行天数极短

### ★3.2 签证欺诈与拒签套利
- **90 天内被拒签 ≥2 次**仍反复申请（拒签史异常，直接拒绝）
- **30 天内申请 ≥3 个不同国家**签证（疑似签证黄牛 / 移民中介，人工审核）
- 护照 / 证件命中黑名单（假护照、挂失护照，直接拒绝）

### ★3.3 退改签滥用 / 行程诈骗
- **0 点-5 点下单 + 行程 < 7 天**（突击出行，疑似代刷 / 骗退）
- 利用"免费取消窗口"反复订退，恶意占用航司 / 酒店资源
- 退改次数 / 退改金额与订单金额异常（薅退改政策）

### 3.4 账户盗用与盗刷
- 新设备 + 异地登录 + 大额订单；修改绑定手机号后立即下单
- 特征线索：设备指纹、登录地、支付账号与历史行为不一致

### 3.5 批量注册薅羊毛
- 同一设备 / 证件注册多个新账号，**注册 < 7 天 + 大额下单**或集中用新人券
- 特征线索：设备指纹关联账号数、账号年龄、实名状态

### 3.6 大额代付与资金异常（反洗钱）
- 同一支付账号短时间代多人付款；大额跨境游订单资金来路异常
- 特征线索：支付账号订单数、单笔金额、跨境占比

## 5. 行业术语表（≥5）

| 术语 | 含义 |
|---|---|
| OTA | 在线旅游平台（Online Travel Agency） |
| GDS | 全球分销系统，机票 / 酒店实时库存与价格来源 |
| PNR | 乘客订座记录（Passenger Name Record），一个订座单元的唯一标识 |
| 出票 | 机票预订确认后生成正式客票（未出票可被占座后取消） |
| 退改签 | 退票 / 改期 / 签转 三类售后行为 |
| 拒签率 | 签证申请被使领馆拒绝的比例，签证风控的核心指标 |
| 切位 / 包机 | 代理商提前买断舱位再分销，黄牛囤票的合法 / 灰色形态 |
| 实名制 | 国内机票 / 火车票购票须实名，乘客证件校验是强约束 |

## 6. 国内监管合规要点

- **《个人信息保护法》**：身份证号、护照号、手机号等敏感信息**加密存储、脱敏展示**；特征计算一律用哈希 / 聚合，禁止明文外泄
- **《数据安全法》**：数据分类分级，敏感数据最小化采集
- **实名制要求**（《民用航空法》等）：机票预订必须校验乘客实名信息一致性
- **签证代办合规**：不得协助伪造申请材料（假在职证明 / 假流水）
- **退改签政策明示**：平台按航司 / 酒店政策公示，风控不得无故拒绝正常退改
- **反洗钱义务**：大额代付、资金归集异常需识别与上报
- **消费者权益保护**：风控拦截须有申诉渠道，避免误杀正常游客

## 7. 风控特征草图（衔接任务 3）

**用户族（旅游版）**
- account_age_days, real_name_status, vip_level
- user_total_orders（历史预订数）, user_orders_30d / user_orders_7d
- user_refund_change_count（退改次数）, user_refund_change_rate
- user_visa_reject_count（历史拒签次数）, user_visa_reject_rate
- user_country_count（申请 / 出行国家数）, user_blacklist_hit（黑名单标记）

**订单族（机票 / 酒店 / 跟团）**
- order_total_amount, order_passenger_count
- order_days_to_depart（提前购票天数，越短越可疑）
- order_is_night（0-5 点下单）, order_is_holiday（节假日出行）
- order_cabin_class（舱位）, order_is_cross_border（跨境）

**目的地族（由电商"地址"族平移）**
- dest_country_count（历史目的地国家数）
- dest_is_high_risk（目的地是否高风险 / 制裁国家）
- passenger_nationality_match（乘客国籍与目的地匹配度）
- same_flight_booking_count（同航班同时段预订数 → 黄牛囤票）
