# 数据库部署

## 当前环境

- MySQL：8.0（当前容器实际版本 8.0.46）
- 数据库：`risk_proj`
- 容器：`risk-proj-mysql`
- 主机端口：`13306`（容器内端口为 `3306`）
- 初始化文件：`db/init.sql`

端口使用 `13306` 是为了避免与本机已有的 3306/3307 服务冲突，可通过 `RISK_MYSQL_PORT` 修改。

## 启停命令

```bash
docker compose up -d
docker compose ps
docker compose logs -f mysql
docker compose down
```

连接示例：

```bash
mysql -h 127.0.0.1 -P 13306 -u risk_user -p risk_proj
```

开发环境默认账号和密码见 `.env.example`。非本地环境必须修改默认密码，不能把真实密码提交到仓库。

## 已初始化内容

- 9 张业务/支撑表：用户、设备、课程、订单、学习进度、退费、黑名单、学历认证、直播打赏。
- 5 张最小风控表：规则、事件、特征快照、评估结果、人工审核案件。
- 8 条首期教育规则：R001、R002、R005、R008、R012、R018、R025、R030。

## 重新初始化

仅在确认可以删除本项目全部数据库数据时执行：

```bash
docker compose down -v
docker compose up -d
```

初始化 SQL 只在数据卷第一次创建时自动执行；普通重启不会覆盖已有数据。
