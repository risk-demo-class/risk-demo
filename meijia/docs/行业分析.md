# 教育风控行业分析

在线教育平台的核心业务链路，是用户以学生、家长或老师等身份完成注册与实名，浏览并购买课程，持续产生学习进度，随后可能发起退费、提交学历认证，或在直播课堂中进行打赏。平台既要保障报名、支付、学习和退款体验，也要确认“账号、学员、课程消费与学习行为”之间真实一致。

主要风险集中在四类场景：一是利用新账号集中报名、虚假交易或大额连报制造流水和套利；二是几乎未学习便频繁退费，或通过多账号、同设备代理学员实施批量退费；三是伪造身份、学号或学历材料，造成认证结果失真；四是新注册直播账号短期大额打赏，可能涉及盗刷、洗钱或诱导消费。黑名单还需要同时覆盖用户 ID、学号、身份证、设备指纹和直播账号，形成跨场景拦截能力。

教育风控与电商风控最大的差异，是风险判断不能只围绕“商品—订单—物流—退货”，而要结合课程这一数字化服务的履约过程。课程通常没有物流和实物退回，是否应退、退多少，需要参考学习分钟数、完成率、活跃时间和课程总课时；身份与学历真实性也比收货地址更关键。此外，直播打赏属于即时虚拟消费，决策时效要求更高。因此教育风控的核心证据，是报名、学习、认证、退费和直播行为能否相互印证。
