## 2. 0:00 - 1:00 业务说明

讲解内容：

1. 一句话定位：基于 AI_Risk 电商风控架构，扩展的旅游 OTA 风控系统。
2. 业务场景：机票、酒店、签证、团票、跨境订单。
3. 旅游特有风险：黄牛囤票、退改套利、酒店预授权异常、签证黑产、备注暗号。
4. 技术方案：规则引擎快速拦截 + XGBoost 精细化评分 + DeepSeek 本地 LLM 辅助。

建议讲稿：

> 这个项目把电商风控抽象成旅游行业的业务模型，核心是规则 + 模型双链路。规则负责快速拦截明显异常，模型负责给每个订单打 0-100 分，再融合成最终决策。

## 4. 3:00 - 4:00 XGBoost 评估

在终端依次执行：

```bash
python scripts/gen_train_csv.py --n 2000 --pos-ratio 0.3
python scripts/train_xgb_model.py
python scripts/evaluate_model.py --threshold 0.3
```

讲解要点：

1. 训练数据：2000 条模拟正负样本，正样本比例 30%。
2. 训练方式：80/20 分层抽样、早停、`scale_pos_weight` 处理不平衡。
3. 评估指标：准确率、精确率、召回率、F1、AUC、混淆矩阵。
4. 当前演示结果：`auc=1.0`、`f1=0.9958`、`accuracy=0.9975`。
5. 强调“不能只看准确率，要对比 baseline accuracy 和最佳 F1 阈值”。

展示文件：

```text

```

## 5. 4:00 - 6:00 业务规则讲解

打开规则管理页面或查询数据库：

```sql
SELECT rule_id, rule_name, risk_level, risk_score, action
FROM risk_rule
WHERE is_enabled = 1 AND deleted_at IS NULL;
```

重点讲解 4-5 条规则：

| 规则 | 说明 |
|---|---|
| R001 拒签历史拦截 | 90 天拒签 >= 2 次直接拒绝 |
| R003 连续退改套利 | 连续退改 >= 3 次人工审核 |
| R006 团票批量下单 | 同支付账号 1 小时 >= 5 单直接拒绝 |
| R008 黄牛囤票 | 同航班 1 小时预订 >= 5 张直接拒绝 |
| R040 备注命中黄牛暗号 | LLM 识别备注风险分 >= 80 |

演示建议：

- 展示规则 JSON 条件表达式。
- 说明“极高风险一票否决”。
- 说明规则分和模型分如何融合。
- 说明规则存在 `risk_rule`，可在线增删改。
