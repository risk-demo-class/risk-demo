# Agent 设计说明

## 1. 目标

用 LLM 协作完成行业风控项目，重点不是手写所有代码，而是把 AI_Risk 电商骨架迁移到旅游业务。

## 2. 协作方式

1. 先让 LLM 输出业务说明和表设计。
2. 复用 AI_Risk 的 5 层架构，只替换业务表、特征、规则、事件类型。
3. 用 LLM 生成造数、训练、评估脚本。
4. 用 LLM 排查报错并补齐测试。

## 3. 本项目 Agent

本项目提供轻量 Agent 路由：

- 案件查询
- 用户画像查询
- 仪表盘统计
- 黑名单管理
- 风控检查

DeepSeek 本地接口用于订单备注语义分析，输出黄牛暗号 / 违规拼团标签。

## 4. 设计哲学

- 工具单一职责，Agent 只做路由。
- LLM 失败不阻塞主链路。
- 配置驱动，业务扩展不修改核心引擎。
