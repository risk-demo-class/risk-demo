# 面试讲解稿

## 1. 项目一句话

基于 AI_Risk 电商风控架构扩展的旅游 OTA 风控系统，规则引擎快速拦截 + XGBoost 精细化评分 + DeepSeek 本地 LLM 辅助识别黄牛暗号。

## 2. 双链路

- 规则链路：JSON 条件表达式，极高风险一票否决，低延迟。
- 模型链路：XGBoost 离线训练，输出 0-100 分，与规则分加权融合。

## 3. 特征工程

- 用户特征：历史订单、7 天 / 30 天下单、退改率、拒签历史。
- 订单特征：金额、乘客数、房晚、航班数、距出发天数、凌晨下单。
- 行为时序：同设备多账号、同支付账号 1 小时订单、连续退改。
- LLM 语义：备注黄牛暗号、违规拼团。

## 4. 模型评估

`scripts/evaluate_model.py` 输出：

- 准确率
- 精确率
- 召回率
- F1
- AUC
- 混淆矩阵
- classification report

面试重点：不平衡数据下不能只看准确率，要比较 baseline accuracy，并用最佳 F1 阈值替代固定 0.5。

## 5. 可靠性

- 模型缺失 / 加载失败自动降级纯规则。
- LLM 超时 / 不可用自动 0 分兜底。
- 全部配置走 `.env` 和 `config/features.yaml`。
- 关键操作写审计日志，案件状态机白名单校验。
