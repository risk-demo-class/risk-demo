# 旅游出行风控业务说明-zls

## 1. 业务边界

用户通过 OTA 平台完成机票、酒店、签证、团票、跟团游等预订与支付。

## 2. 典型欺诈场景

1. 黄牛囤票：同一支付账号 / 设备 1 小时批量预订同航班。
2. 退改套利：连续改签高价票、退票险套利。
3. 酒店预授权异常：预授权金额与实际扣款不一致。
4. 团票批量下单：短时间多账号 / 多单批量拼团。
5. 跨境大额订单：新账号短时间大额跨境游。
6. 签证黑产：90 天拒签多次、30 天多国申请。
7. 设备聚集：同一设备 7 天关联多个账号订酒店。
8. 备注暗号：订单备注包含黄牛暗号 / 违规拼团信息。

## 3. 关键业务字段

`order_id`、`user_id`、`order_type`、`total_amount`、`dest_country`、
`depart_date`、`return_date`、`passenger_count`、`pay_account`、
`device_id`、`ip_address`、`order_remark`、`flight_no`、
`hotel_id`、`check_in`、`check_out`、`preauth_amount`、`passport_no`。

## 4. 业务事件类型

- 下单
- 支付
- 退改申请
- 签证申请
- 拼团报名

## 5. 行业术语表

| 术语 | 说明 |
|---|---|
| OTA | 在线旅游平台 |
| PNR | 乘客订座记录 |
| 退改 | 机票 / 酒店退票、改签 |
| 预授权 | 酒店先冻结后扣款 |
| 团票 | 批量 / 拼团购票 |
| 黄牛暗号 | 备注中用于绕过风控的黑话 |

WHERE is_enabled = 1 AND deleted_at IS NULL;

预期结果：

- 规则数量 >= 5 条。
- 样例数据至少命中 3 条规则。
