### 核心字段变更

**WaybillInfo 新增字段**：
- `segment` (A/B/C 三段式链路标识)
- `inspection_record_id` (关联验货报告)
- `seal_id` (封条/防拆贴)
- `cargo_type` (危险品分类枚举)
- `is_cross_border` (跨境标识)
- 保留：重量/体积/价值/COD/保价/夜间下单/加急

**WaybillDetail 新增字段**：
- `item_imei` (序列号/IMEI)
- `item_brand` / `item_model` (品牌/型号)
- `item_grade` (成色：优/良/差)

**ShipperInfo 画像字段**：`trade_total` / `dispute_count` / `cancel_count` / `wb_total` / `complaint_total`

**ConsigneeInfo 画像字段**：`sign_count` / `return_count` / `return_rate`

**CarrierInfo 画像字段**：`deliver_total` / `photo_rate` / `complaint_total`

## 二、数据库 DDL（`sql/init_logistics_tables.sql`）

### 命名变更
`init_business_tables.sql` → `init_logistics_tables.sql`（跟随业务名替换规则）

### 建表数量
17 张电商表 → 12 张物流表（维度表 5 张 + 核心表 7 张）

### 关键 DDL 修改

| 表 | 字段类型变更 | 原因 |
|---|---|---|
| `waybill_info.cargo_volume` | `decimal(10,2)` → `decimal(10,4)` | 体积值需要 3-4 位小数（如 0.003 m³） |
| `waybill_detail.cargo_volume` | `decimal(10,2)` → `decimal(10,4)` | 同上 |
| `item_identity.item_imei` | `varchar(50) NOT NULL` | 调包检测核心，非空 |
| `inspection_record.item_imei` | `varchar(50) NOT NULL` | 验货记录关联序列号，非空 |
| `tracking_event.node_weight` | `decimal(10,2)` | 新增节点称重字段 |
| `waybill_info.inspection_record_id` | `varchar(50)` | 关联验货报告 |
| `waybill_info.seal_id` | `varchar(50)` | 封条/防拆贴ID |

### 运单状态维度表替换
`waybill_status` → `dimension_waybill_status`（8 种物流状态：待揽收/待验货/已验货/运输中/派送中/已签收/已拒收/已退回）

### 品类维度表替换
`cargo_category` → `dimension_cargo_category`（12 种二手品类，含 `is_high_value` 高溢价标记）

### 投诉原因表
`complaint_reason` 保留，内容改为物流相关（成色不符/调包/假货/未收到/七天无理由/保价理赔难）
