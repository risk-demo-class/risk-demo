## 独立数据库

- 教育项目数据库：`ai_risk_education`
- 教育测试数据库：`ai_risk_education_test`
- 老师原数据库 `ecs` 保留不动，不再作为本项目默认连接库。
- 复制根目录 `.env.example` 为 `.env`，填写本机数据库密码和自己的 `LLM_API_KEY`。
- 执行 `python scripts/init_db.py --reset --yes` 可重新初始化 16 张表、教育业务数据和 12 条规则。该命令只重置当前配置的教育数据库。

## 仪表盘测试数据

执行下面的命令，会复用教育业务数据执行真实风控流水线，默认向当前教育数据库追加过去 7 天每天 10 条、共 70 条评估记录：

```powershell
python scripts/gen_education_risk_data.py --days 7 --per-day 10
```

默认高风险样本抽取比例为 10%，可通过 `--positive-ratio 0.05` 等参数调整；普通池使用 2999 元及以下课程报名和小额直播打赏。脚本不会清空已有评估数据，重复执行会继续追加。
