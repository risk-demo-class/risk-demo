# P4 升级报告：产品交互与用户认证

## 对应改进项

1. 仪表盘四张指标卡改为可点击链接；新增患者管理，“合成患者”统一改为“患者”，管理界面移除教学化文案。
2. 规则管理支持人工新增、启停和软删除；条件仅允许使用既有 25 维特征与安全运算符；全部变更写审计日志。
3. 案件支持指定审核人；已通过、已拒绝、已关闭案件可以填写原因并重新发起审核。
4. 评估历史行可点击，详情展示事件源、患者、规则、模型概率、案件状态和 25 维特征证据。
5. AI 助手发送问题后展示“正在分析风险数据”动画，完成或失败后恢复输入状态。
6. 新增登录、公开注册、退出、个人改密、管理员创建用户、角色调整、启停和密码重置。

## 安全实现

- 默认超级用户 `admin / admin` 仅用于首次本地登录，密码以 Argon2 摘要保存。
- 会话 Cookie 使用独立随机密钥签名、HttpOnly、SameSite=Lax，并配置 8 小时有效期。
- 角色包括 admin、reviewer、analyst、viewer；写操作在 API 后端强制校验。
- 超级用户不能被降级或停用；用户审计日志不记录任何密码或密码摘要。
- P4 迁移不删除表和数据，并拒绝对 `ecs` 数据库执行。
