# 物流风控业务说明

> 交付物：任务 1（业务理解）| 行业：物流（场景 E）

## 1. 行业典型欺诈场景（≥3 种）

### 场景一：危险品瞒报
寄件人将锂电池、化学品、液体等禁限运品伪装成普通物品寄递，不上报或低报，
逃避安检与实名登记。风险：运输安全事故（起火/泄漏）、承运方被处罚。
特征信号：运单明细出现"电池/化学品/液体"但 `is_dangerous_declared=0`；
同一寄件人反复出现该类运单。

### 场景二：代收货款（COD）恶意拒收
黑产用 COD 模式大量发货，收货人拒收造成运费与货损损失；或"货到付款"欺诈买家
（假货/空包裹）。特征信号：单个寄件人 COD 拒收率高、新收件地址 + 大额 COD、
凌晨批量下 COD 单。

### 场景三：跨境包裹价值虚报
跨境申报时低报价值逃税（申报 100 元但重量 10kg），或高报价值骗保骗赔。
特征信号：跨境运单申报价值与重量/物品明显不匹配。

### 场景四：高频/批量寄件（黄牛与灰产）
同一寄件人短期内高频寄件（刷单、代购跑腿、灰产物料分发），常发生在凌晨，
跨省、多地址、短账号龄。特征信号：近 7 天寄件 ≥ 10 单、夜间寄件、新账号大单。

### 场景五：实名与黑名单绕过
未实名寄件、身份证号/手机号/收件地址命中黑名单（涉毒涉假），用临时地址或
新手机号绕开拦截。

## 2. 关键业务字段（≥10 个）

| 字段 | 所属表 | 风控含义 |
|---|---|---|
| `real_name_status` | user_info | 是否实名 |
| `id_number_hash` | user_info | 身份证号（黑名单匹配） |
| `account_age_days` | user_info | 账号年龄 |
| `shipment_type` | shipment | 普通/跨境/代收货款 |
| `weight_kg` | shipment | 重量（价值匹配校验） |
| `declared_value` | shipment | 申报价值 |
| `cod_amount` | shipment | 代收金额 |
| `is_dangerous_declared` | shipment | 是否如实申报危险品 |
| `is_rejected` | shipment | 是否拒收 |
| `item_category` | shipment_item | 物品类别（危险品识别） |
| `use_count` | address | 地址新旧程度 |
| `is_temp` | address | 是否临时地址 |

## 3. 业务事件类型（≥3 种）

1. `寄件` — 普通包裹寄递
2. `跨境申报` — 跨境包裹申报
3. `代收货款` — 货到付款 COD
4. `实名认证` — 寄件人实名核验

## 4. 行业术语表（≥5 个）

| 术语 | 含义 |
|---|---|
| 运单号 (Waybill No.) | 一次寄递的唯一标识 |
| 面单 | 贴在包裹上的寄递单据 |
| COD（货到付款） | Cash on Delivery，代收货款 |
| 申报价值 | 寄递/报关时申报的货值 |
| 禁限运品 | 禁止/限制寄递的物品（含危险品） |
| 保税/报关单 | 跨境寄递的申报文件 |
| 揽收 | 快递员上门收件 |
