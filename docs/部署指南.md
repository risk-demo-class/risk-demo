# 部署指南

## 1. 前置服务

| 服务 | 用途 | 必需 | 参考地址 |
| --- | --- | --- | --- |
| Milvus | 向量检索 | 是 | `http://192.168.100.100:19530` |
| MongoDB | 多轮对话历史 | 是 | `mongodb://192.168.100.100:27017` |
| LLM API（DashScope 兼容模式） | 意图分析 / 元数据识别 / 答案生成 / HyDE | 是 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| BGE-M3 模型 | 文本向量化 | 是 | 首次运行自动下载 |
| MinIO | 课程图片托管 | 否（失败回退本地路径） | `192.168.100.100:9000` |
| MinerU | PDF → Markdown | 否（仅导入 PDF 时需要） | `https://mineru.net/api/v4` |
| DashScope TextReRank | 重排序 | 否（未配置时按 RRF 顺序兜底） | — |
| 百炼 Web Search MCP | 网络搜索 | 否（未配置自动跳过） | — |

## 2. 环境配置

```bash
cd 教育实战
copy .env.example .env
```

填写 `.env`：

```ini
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_DEFAULT_MODEL=qwen-flash

MILVUS_URL=http://192.168.100.100:19530
MONGO_URL=mongodb://192.168.100.100:27017
MONGO_DB_NAME=edu_knowledge_base

BGE_M3_PATH=BAAI/bge-m3
BGE_DEVICE=cpu        # 有 GPU 可改为 cuda

MINIO_ENDPOINT=192.168.100.100:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET_NAME=edu-knowledge-base

DATA_BASED_ROOT_DIR=D:/edu_data
```

## 3. 安装依赖

```bash
uv sync
```

或使用 pip：

```bash
python -m venv .venv
.venv\Scripts\activate
pip install fastapi uvicorn langgraph langchain langchain-openai langchain-text-splitters \
    pymilvus[model] pymongo minio dashscope python-dotenv colorlog openai-agents \

```

## 4. 导入数据

### 4.1 一键导入（推荐）

```bash
python scripts/import_education_data.py
```

默认定位真实教育数据目录；也可导入演示数据：

```bash
python scripts/import_education_data.py --data-root data/demo
```

### 4.2 页面导入

```bash
uvicorn edu_kb.web.api.import_service:app --host 0.0.0.0 --port 8000
```

打开 `http://127.0.0.1:8000/import.html`，上传文件并选择内容类型（或自动识别），页面实时展示节点进度与耗时。

## 5. 启动问答服务

```bash
uvicorn edu_kb.web.api.query_service:app --host 0.0.0.0 --port 8001
```

打开 `http://127.0.0.1:8001/chat.html`。

## 6. API 一览

### 导入服务（8000）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/upload` | 上传文件并触发导入（表单字段：file、content_type 可选） |
| GET | `/status/{task_id}` | 查询导入任务状态与节点进度 |
| GET | `/import.html` | 导入页面 |

### 查询服务（8001）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/query` | 提交问题，返回 session_id + task_id |
| GET | `/stream/{task_id}` | SSE 流式结果（progress / delta / final / error） |
| GET | `/history/{session_id}` | 查询会话历史 |
| DELETE | `/history/{session_id}` | 清空会话历史 |
| GET | `/chat.html` | 对话页面 |

## 7. 常见问题

**Q：导入课程介绍时提示 Milvus 连接失败？**

检查 `MILVUS_URL` 是否正确、Milvus 是否已启动；集合会在首次导入时自动创建。

**Q：BGE-M3 模型下载很慢？**

首次运行需要下载模型（约 2GB+），建议提前设置 `HF_ENDPOINT` 镜像，或使用课程资料中的本地模型路径配置 `BGE_M3_PATH`。

**Q：没有 DashScope Rerank 权限怎么办？**

不配置 `TEXT_RERANK_MODEL` 即可，重排节点会自动回退到 RRF 顺序，不影响主流程。

**Q：没有 MinIO 能导入吗？**

能。docx 转换出的图片会保留本地路径；有 MinIO 时自动上传并替换为远程 URL。
