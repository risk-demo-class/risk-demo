# 教育行业 AI 风控系统 — 操作手册

> 适用范围：一期规则引擎闭环（课程报名 / 退费申请 / 学历认证 三类事件的风险检查、规则、案件、评估、黑名单、仪表盘）。
> 配套文档：[SPEC.md](../SPEC.md)（技术规格）、[README.md](../README.md)（快速开始）。

---

## 1. 系统简介

- **技术栈**：Python 3.11+ / FastAPI / SQLAlchemy / SQLite，uv 管理依赖
- **数据库**：项目根目录 `education_risk.db`（可用环境变量 `EDUCATION_RISK_DATABASE_URL` 切换）
- **决策流程**：请求 → 来源校验 → 黑名单预拦截 → 特征计算 → 规则匹配 → 评分决策 → 落库（评估/事件/特征/案件）
- **决策档位**：`通过` / `标记` / `人工审核` / `拒绝`（黑名单命中为拒绝，一票否决）

## 2. 安装与启动

### 2.1 首次安装（新机器 / 重新克隆）

```powershell
cd D:\PythonProject\vibecoding1\education_risk
uv sync                        # 创建 .venv 并安装依赖（生成 uv.lock）
uv run python -m app.seed      # 初始化模拟教育数据
uv run pytest                  # 冒烟：应为 23 passed
```

### 2.2 启动服务

```powershell
cd D:\PythonProject\vibecoding1\education_risk
uv run uvicorn app.main:app --reload
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。

| 入口 | 地址 | 用途 |
|---|---|---|
| 运营后台 | http://127.0.0.1:8000/ | 仪表盘 + 6 个运营页面 |
| API 文档 | http://127.0.0.1:8000/docs | Swagger 在线调试 |

停止服务：按 `Ctrl+C`。端口被占用时换端口：`uv run uvicorn app.main:app --reload --port 9000`。

## 3. 运营后台页面操作

导航在左侧边栏，共 6 个页面：

| 页面 | 地址 | 操作说明 |
|---|---|---|
| 仪表盘 | `/` | 今日评估数、高风险数、待审核案件、通过率、近 7 日趋势、规则命中 TOP5 |
| 风险检查 | `/risk-check` | 输入 `事件类型 / 来源单号 / 学员ID` 发起一次风控检查，实时查看命中规则与决策 |
| 规则管理 | `/rules` | 查看已启用规则（ID、名称、适用事件、风险分、处置动作） |
| 案件管理 | `/cases` | 查看高风险产生的案件，按状态筛选（待审核/审核中/已通过/已拒绝/已关闭），对案件执行审核 |
| 评估历史 | `/assessments` | 查看全部风险检查的评估记录（分数、等级、决策、事件） |
| 黑名单管理 | `/blacklist` | 新增/删除 用户、证件哈希、设备哈希 三类黑名单；命中黑名单的请求直接拒绝 |

**案件审核流转规则**：

```
待审核 ──► 审核中 ──► 已通过 / 已拒绝 / 已关闭
   │
   └────────────► 已通过 / 已拒绝 / 已关闭
```

终态（已通过/已拒绝/已关闭）不可再流转，重复审核返回 400。

## 4. API 接口手册

Base URL：`http://127.0.0.1:8000`。统一错误格式：`{"detail": "..."}`。
错误码：`404` 来源不存在 · `403` 来源不属于该用户 · `422` 输入格式错误 · `400` 非法操作。

### 4.1 风险检查（核心）

**`POST /api/risk/check`**

| 字段 | 类型 | 说明 |
|---|---|---|
| `event_type` | string | 枚举：`课程报名` / `退费申请` / `学历认证` |
| `source_id` | string | 业务来源单号（报名单/退款单/认证单） |
| `user_id` | string | 学员 ID |

请求：

```json
{
  "event_type": "课程报名",
  "source_id": "ENR-RISK-001",
  "user_id": "STU-RISK-01"
}
```

响应（示例）：

```json
{
  "event_id": "EVT-BE0B19A22FC24AA5",
  "assessment_id": "ASM-42393BDAA7C94110",
  "user_id": "STU-RISK-01",
  "final_score": 65,
  "risk_level": "中风险",
  "decision": "人工审核",
  "rule_count": 1,
  "triggered_rules": [
    {"rule_id": "EDU-RULE-001", "rule_name": "七日内共享设备关联多个新报名账号", "risk_score": 65}
  ],
  "blocked_by": null
}
```

`blocked_by` 非空表示被黑名单拦截（如 `用户黑名单`），此时不计算规则。

### 4.2 规则查询

**`GET /api/rules?page=1&page_size=20`** → `{items, total, page, page_size}`

### 4.3 案件

**`GET /api/cases?status=&active_only=&page=&page_size=`**

- `status`：按状态筛选；`active_only=true`：只看待审核/审核中

**`POST /api/cases/{case_id}/review`**

```json
{"decision": "已通过"}
```

`decision` 枚举：`审核中` / `已通过` / `已拒绝` / `已关闭`。非法流转返回 400，案件不存在返回 404。

### 4.4 评估历史

**`GET /api/assessments?page=&page_size=`** → 按时间倒序返回评估记录。

### 4.5 黑名单

**`GET /api/blacklist?blacklist_type=用户&page=&page_size=`**

- `blacklist_type` 枚举：`用户` / `证件哈希` / `设备哈希`

**`POST /api/blacklist`**（新增，201）

```json
{
  "blacklist_type": "用户",
  "blacklist_value": "STU-BLACK-002",
  "reason": "确认作弊账号"
}
```

**`DELETE /api/blacklist/{blacklist_id}`** → `{"detail": "已移除"}`；不存在返回 404。

### 4.6 仪表盘

**`GET /api/dashboard/overview`** → 今日评估/高风险、待审核案件、通过率、近 7 日趋势、规则命中 TOP5。

## 5. 内置演示数据

| 学员 | 事件 | 预期结果 |
|---|---|---|
| `STU-NORMAL-001` + `ENR-NORMAL-001` | 课程报名 | 通过 |
| `STU-RISK-01` ~ `STU-RISK-05`（共享设备）+ `ENR-RISK-001` | 课程报名 | 人工审核（EDU-RULE-001） |
| `STU-BLACK-001` + `ENR-BLACK-001` | 课程报名 | 拒绝（用户黑名单） |
| `STU-REFUND-001` + `REF-RISK-001` | 退费申请 | 人工审核（EDU-RULE-REFUND-001） |
| `STU-VERIFY-001` + `VER-RISK-001` | 学历认证 | 人工审核（EDU-RULE-VERIFY-001） |

内置规则（3 条）：

| 规则 ID | 规则名 | 触发条件 | 分数 | 动作 |
|---|---|---|---|---|
| EDU-RULE-001 | 七日内共享设备关联多个新报名账号 | 关联账号数 ≥ 5 | 65 | 人工审核 |
| EDU-RULE-REFUND-001 | 学习不足五分钟即申请退款 | 退款前学习分钟 ≤ 5 | 65 | 人工审核 |
| EDU-RULE-VERIFY-001 | 三十天内连续学历认证失败 | 失败次数 ≥ 3 | 65 | 人工审核 |

## 7. 常见问题（FAQ）

| 现象 | 原因与处理 |
|---|---|
| `No module named uvicorn` | 没用虚拟环境。改用 `uv run uvicorn ...`，或先 `uv sync` |
| `uv 不是内部或外部命令` | 未安装 uv：`pip install uv` 或官网安装后重开终端 |
| 端口 8000 被占用 | 换端口：`uv run uvicorn app.main:app --reload --port 9000` |
| 想重置演示数据 | 停止服务 → 删除 `education_risk.db` → `uv run python -m app.seed` 重新初始化 |
| 页面中文乱码 | 确认请求/响应均为 UTF-8；调试接口建议直接用 `/docs` 页面 |
| 案件重复审核报 400 | 终态案件不可再流转，属预期行为 |
| 测试失败 | 确认执行的是 `uv run pytest`；临时库机制下不应出现偶发失败 |
