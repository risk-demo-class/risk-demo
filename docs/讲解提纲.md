# 讲解提纲（5-8 分钟，3 段式）

## 第一段：30 秒痛点

医保基金欺诈是真实且高发的风险：医保卡盗刷、医生统方、挂号黄牛、处方超量、药品代购，人工稽核面对海量结算记录力不从心。需要一个"规则可解释 + 模型能召回"的风控系统，把异常从结算/处方/挂号/购药四大环节里捞出来。

## 第二段：3 分钟演示

1. 打开 http://localhost:8000，先展示规则管理页——11 条医疗规则（R001 医保卡盗刷、R002 医生统方、R004 处方超量…），条件可读、等级/动作清晰
2. 造数 → 风险检查：选一个 RISK 高风险用户触发检查，展示规则命中 + 证据链 + ML 评分 + 拒绝决策
3. 案件工作台：1850 条已拒绝案件，按机构风险/处方风险分类，ML 评分非 0
4. 一句话带过 AI 稽核助手：可查业务数据（结算/处方/挂号/药品订单），辅助人工复核

## 第三段：2 分钟总结 + 30 秒反思

**总结（复用 vs 重写）：**

- 复用：风控核心 9 张表 + 决策流水线（process_event 4 步 / run_risk_check 7 步）+ 规则引擎 + XGBoost 训练管线，契约不变
- 重写：8 张医疗业务表、25 维医疗特征（用户 17 + 业务单 8）、11 条规则、8 种风险模式造数
- 指标：val_auc=1.0 / val_f1=1.0 / 414 测试全绿

**反思（诚实点）：**

- 教学强标注数据下指标饱和（1.0），真实场景需要人工稽核标注回流，指标会回到合理区间
- 学到最深的：业务层换行业 = 数据模型/特征/规则三件套全换，风控抽象本身可复用
- Vibe Coding 过程：AI 负责 schema/特征/规则草案，业务合理性自己把关（"为什么这条规则有效"）
