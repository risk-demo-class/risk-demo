# 需求实现对照

对照《教育知识库项目实战需求说明》逐项说明本项目的实现方式。

## 2. 项目目标与功能范围

| 需求项 | 实现位置 | 说明 |
| --- | --- | --- |
| 内容导入：课程资料、项目文档、讲义、题库 | `edu_kb/import_process` | 支持 `课程介绍.md`（课程）、`题目资料.md`（题库）、`课程文档/*.docx`（讲义）、`项目文档/*.docx`（项目文档） |
| 任务状态追踪 | `edu_kb/utils/task_utils.py` + `web/api/import_service.py` | 上传/导入任务支持 processing / completed / failed 状态，记录节点级进度与耗时，前端轮询 `/status/{task_id}` |
| 元数据管理 | `node_metadata_recognition`、`node_course_intro_import`、`node_question_bank_import` | 课程名、项目名、章节名、题库名、题目编码、题型、来源文件名、来源路径全部入库并可检索 |
| 课程检索与介绍 | `node_search_course` | 按课程名、系列名、知识点向量检索 `edu_courses`，返回课程列表与详情（定位/适合人群/学习目标/章节结构） |
| 文档检索 | `node_search_docs` + `node_search_docs_hyde` | 向量检索 `edu_chunks`，返回课程名、项目名、章节名、文件名等来源信息；HyDE 提升召回 |
| 题库检索 | `node_search_questions` | 向量检索 `edu_questions`，返回题目内容、题型、选项、答案与解析，附带题库名与题目编码 |
| 知识问答 | `node_answer_output` | 基于检索片段流式生成答案，答案中标注来源编号，并返回结构化引用信息 |
| 单轮问答 | `query_service /query` | 支持无历史会话的独立提问 |
| 多轮对话 | `node_query_analyze` + MongoDB 历史 | 历史会话参与意图分析、指代消解与答案生成 |
| 流式输出 | `sse_utils_sync.py` + `query_service /stream/{task_id}` | SSE 推送 progress / delta / final / error 事件 |
| 历史记录管理 | `mongo_history_utils.py` + `/history/{session_id}` | 历史查询 / 清空 |

## 4. 典型业务场景

| 场景 | 示例问题 | 处理链路 |
| --- | --- | --- |
| 课程介绍 | “有哪些 Python 相关课程” | 意图识别(course_intro) → 课程检索 → 课程列表/定位/适合人群/学习目标 |
| 课程详情 | “Python 课程有哪些章节” | 意图识别(course_detail) → 课程检索 + 文档检索 → 章节结构 + 讲义内容 |
| 课程文档检索 | “FastAPI 里什么是协程” | 意图识别(doc_retrieval/qa) → 文档检索(+HyDE) → RRF/Rerank → 生成答案 + 引用（课程/章节/文件） |
| 题目检索 | “Python 有哪些练习题 / 函数相关的选择题” | 意图识别(question) → 题目检索 → 输出题干/选项/答案/解析 + 题库/题目编码 |

## 5. 内容字段要求

| 字段 | 存储位置 |
| --- | --- |
| 内容正文 | `edu_chunks.content` / `edu_questions.question_text` / `edu_courses.search_text` |
| 内容类型 | `edu_chunks.content_type`（course_intro / course_doc / project_doc / question） |
| 课程名称 | `edu_chunks.course_name`、`edu_courses.course_name` |
| 项目名称 | `edu_chunks.project_name` |
| 章节名称 | `edu_chunks.chapter_name`（由切分标题生成） |
| 题库名称 | `edu_questions.bank_name` |
| 题目编码 | `edu_questions.question_code` |
| 题型 | `edu_questions.question_type` |
| 来源文件名 | `edu_chunks.file_title` / `edu_questions.source_file` / `edu_courses.source_file` |
| 来源路径 | `edu_chunks.source_path` |

## 6. 质量要求

| 要求 | 实现 |
| --- | --- |
| 基础异常处理 | 每个节点 try/except + 日志；非核心失败（MinIO、reranker、MCP、历史写入）不中断主流程；单个文件导入失败不影响其他文件与服务 |
| 准确、可解释、可追溯 | 答案要求基于参考内容并标注来源编号；final 事件返回结构化引用（课程/项目/章节/文件/题库/题目编码/相关度） |
| 流式实时性 | 节点进度走 SSE progress 实时推送；答案按 token 增量推送 delta |
| 清晰分层 | config / utils / import_process / query_process / web 五层分离，实体与意图常量集中管理，便于扩展 |

## 7. 后续扩展方向的预留

- 课程后台管理与知识库管理页面：`web/page` 可扩展管理页，Milvus 集合已按内容类型隔离
- 文档增量更新：导入节点按 `file_title + content_type` 幂等清理，重传即增量更新
- 权限控制与多租户：Milvus 集合可增加 tenant 字段、MongoDB 会话可挂用户 ID
- 学习路径推荐 / 能力测评：`edu_courses.goals`、`edu_questions.question_type` 已结构化，可直接扩展
- 视频检索：可新增视频字幕集合，复用本项目的集合创建与混合检索模式
