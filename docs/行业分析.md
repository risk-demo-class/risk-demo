# 医疗风控行业分析

## 核心业务是什么

医疗风控聚焦医保基金使用的四个高风险环节：

1. 医保结算：参保人持医保卡就医、结算报销，涉及医保基金支出
2. 处方审核：医生开具处方、药房发药，涉及用药合理性
3. 挂号：门诊 / 专家号预约，涉及医疗资源分配
4. 药品代购：处方药经第三方渠道流转购买，涉及处方外流监管

## 风险点在哪里

- 医保卡盗刷：同一张卡短时间内跨多家医院结算
- 医生统方：单个医生集中开具大量处方（疑似利益输送）
- 挂号黄牛：反复抢号、取消、转卖专家号
- 处方超量 / 超适应症：超出临床常规剂量或与诊断不符
- 虚假病历：同一诊断编码批量套用不同患者
- 药品代购：处方药订单收件人非患者本人
- 异地集中结算：参保地与就医地分离的异常集中报销

## 跟电商比最大差异

1. **数据域不同**：电商核心是订单 / 支付 / 设备指纹；医疗核心是患者 / 医生 / 医院 / 处方 / 医保结算，新增"医生"（内部人）和"医院"（机构）两个风控维度。
2. **强监管**：医保结算受医保目录、诊疗规范约束，规则有版本、有生效日期；电商规则则多为平台自定义策略。
3. **决策性质不同**：电商拦截一笔交易损失有限；医疗误判会阻碍正常诊疗，因此需要"规则命中 → 人工审核"闭环，可解释性要求更高。
4. **风险主体不同**：电商主要防"用户"；医疗要同时防患者（盗刷）、医生（统方）、机构（套保）三类主体。

## 结论

风控抽象（事件驱动 + 特征 + 规则 + 模型双轨）可复用，但业务层（数据模型 / 特征 / 规则）必须按医疗场景重写。
