# 架构与数据模型

## 1. 总体架构

```text
┌────────────────────────── Web 层（FastAPI） ──────────────────────────┐
│  导入服务 /import.html（8000）        查询服务 /chat.html（8001）      │
│  POST /upload      GET /status/{id}   POST /query   GET /stream/{id}  │
└──────┬──────────────────────────────────────┬─────────────────────────┘
       │ 后台任务                              │ 后台任务
       ▼                                      ▼
┌─────────────── 导入工作流（LangGraph） ──────────────┐ ┌──────────── 查询工作流（LangGraph） ────────────┐
│ node_entry → node_doc_to_md → node_md_img          │ │ node_query_analyze                              │
│  ├─ course_intro → node_course_intro_import        │ │   ├─ [澄清] → node_answer_output               │
│  ├─ question    → node_question_bank_import        │ │   └─ [多路检索] node_search_course             │
│  └─ 文档         → node_document_split              │ │                 node_search_docs (+HyDE)        │
│              → node_metadata_recognition            │ │                 node_search_questions           │
│              → node_bge_embedding                   │ │                 node_web_search_mcp             │
│              → node_import_milvus                   │ │   → node_join → node_rrf → node_rerank         │
│  → node_import_entity_index                         │ │   → node_answer_output（流式 + 引用）           │
└──────────────┬─────────────────────────────────────┘ └───────────────────┬──────────────────────────────┘
               ▼                                                           ▼
┌────────────────────────────── 存储层 ─────────────────────────────────────────┐
│ Milvus: edu_courses / edu_chunks / edu_questions / edu_entities              │
│ MongoDB: chat_message（多轮对话历史）  MinIO: 课程图片                         │
└───────────────────────────────────────────────────────────────────────────────┘
```

## 2. 导入流程

1. **入口节点**：校验文件，识别文件类型（md / docx / pdf）与内容类型（课程介绍 / 课程文档 / 项目文档 / 题库）。
2. **文档转 Markdown**：docx 使用纯标准库解析（标题样式、代码块、表格、图片）；pdf 使用 MinerU；md 直接读取。
3. **图片处理**：调用 VLM 生成图片摘要，上传 MinIO（失败回退本地路径），替换 Markdown 图片引用。
4. **分流**：
   - 课程介绍：解析出课程记录（系列 + 课程 + 定位/人群/目标）→ 向量化 → `edu_courses`；
   - 题库：解析出题目记录（题型/题干/选项/答案/解析）→ 向量化 → `edu_questions`；
   - 文档：按标题切分（长切短合）→ LLM 识别课程名/项目名/章节/知识点（失败按文件名兜底）→ BGE-M3 混合向量化 → `edu_chunks`。
5. **知识实体索引**：课程名 / 项目名 / 题库名写入 `edu_entities`，供查询侧实体对齐。

## 3. 查询流程

1. **意图分析**：LLM 提取意图（course_intro / course_detail / doc_retrieval / question / qa）与知识实体，改写问题；失败时关键词兜底。
2. **实体对齐**：课程/项目/题库名在 `edu_entities` 中做混合检索，评分 >0.85 确认，0.6~0.85 作为澄清候选。
3. **多路检索**（并行）：
   - 课程检索：`edu_courses` 向量检索（可加课程名/系列名过滤）；
   - 文档检索：`edu_chunks` 向量检索（限 course_doc / project_doc，可加课程/项目过滤）；
   - HyDE 文档检索：LLM 生成假设性答案后检索；
   - 题目检索：`edu_questions` 向量检索（可加题库名过滤）；
   - 网络搜索：MCP（可选，未配置自动跳过）。
4. **融合重排**：RRF 倒排融合（向量路权重 1.0、HyDE 路 0.8）→ Rerank 精排（未配置时按 RRF 顺序兜底）。
5. **答案生成**：按意图组装参考内容（课程/题目/文档）→ LLM 流式生成 → SSE 推送 delta → final 事件携带答案、引用信息与图片。

## 4. Milvus 数据模型

### edu_courses（课程介绍）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| course_id | INT64 (PK) | 自增主键 |
| course_code / course_name | VARCHAR | 课程编码 / 课程名 |
| series_code / series_name | VARCHAR | 系列编码 / 系列名 |
| category / suitable_for / goals / grade | VARCHAR | 分类 / 适合人群 / 学习目标 / 适合年级 |
| class_hours / period | VARCHAR | 课时 / 学时 |
| description / series_description | VARCHAR | 课程定位 / 系列描述 |
| source_file | VARCHAR | 来源文件名 |
| search_text | VARCHAR | 向量化检索文本 |
| dense_vector / sparse_vector | 向量 | BGE-M3 稠密 + 稀疏 |

### edu_chunks（文档切片）

| 字段 | 说明 |
| --- | --- |
| chunk_id | 主键 |
| content / title / parent_title / part | 内容 / 标题 / 父标题 / 分段序号 |
| content_type | course_doc / project_doc |
| course_name / project_name / chapter_name | 课程名 / 项目名 / 章节名 |
| file_title / source_path | 来源文件名 / 来源路径 |
| dense_vector / sparse_vector | 向量 |

### edu_questions（题库题目）

| 字段 | 说明 |
| --- | --- |
| question_id | 主键 |
| question_code / bank_code / bank_name | 题目编码 / 题库编码 / 题库名 |
| question_type | 题型（单选 / 多选 / 判断 / 简答 / 编程等） |
| question_text / options / answer / analysis | 题干 / 选项 / 答案 / 解析 |
| source_file | 来源文件名 |
| dense_vector / sparse_vector | 向量 |

### edu_entities（知识实体索引）

| 字段 | 说明 |
| --- | --- |
| pk | 主键 |
| entity_name / entity_type | 实体名 / 类型（course / project / question_bank） |
| source_file | 注册来源 |
| dense_vector / sparse_vector | 向量 |

## 5. MongoDB 历史记录

集合 `chat_message`，按 `session_id + ts` 建索引：

```json
{
  "session_id": "...",
  "role": "user | assistant",
  "text": "消息内容",
  "rewritten_query": "改写后的问题",
  "entities": ["Python"],
  "references": [{"type": "doc", "course_name": "...", "file_title": "..."}],
  "image_urls": [],
  "intent": "qa",
  "ts": 1234567890
}
```
