# 规则设计（场景 F：医疗风控）

规则编号 / 名称 / 触发条件 / 风险等级 / 决策 / 为什么有效。任务书给出 8 条种子规则，本设计扩展至 19 条（R013-R020 参考国家医保局智能监管规则库 / 医保基金监管常见违规场景）。

| 编号 | 规则名 | 触发条件 | 风险等级 | 决策 | 为什么有效 |
|---|---|---|---|---|---|
| R001 | 医保卡盗刷 | 同一医保卡累计 ≥3 家不同医院结算且结算 ≥3 次 | 极高 | 拒绝 + 人工调查 | 正常参保人不会长期分散在多院结算，是盗刷/冒用的强信号 |
| R002 | 医生统方 | 同一医生 1 天内 ≥50 张处方 + 涉及 ≥10 个不同患者 | 极高 | 人工审核 + 风控介入 | 单日开方量远超临床负荷，疑似利益输送 |
| R003 | 挂号黄牛 | 同一手机号 24 小时内取消挂号 ≥5 次 | 高 | 人工审核 | 反复抢号-取消是转卖号源的典型动作 |
| R004 | 处方超量 | 单张处方药品数量超临床常规上限（如阿普唑仑 >30 片） | 极高 | 拒绝发药 | 超说明书剂量是滥用的直接证据 |
| R005 | 虚假病历 | 同一诊断编码 1 周内 ≥5 个不同患者 + 同一医生 | 高 | 人工审核 | 同一诊断批量套用不同患者，疑似虚构就诊 |
| R006 | 药品代购 | 处方药订单收件人 ≠ 患者本人 + 累计金额 >5000 | 中 | 标记 | 处方药代购绕过实名用药监管 |
| R007 | 异地集中结算 | 参保地 ≠ 就医地 + 1 个月内 ≥3 次结算 + 累计 >1 万 | 中 | 标记 | 异地高频集中结算，疑似套取基金 |
| R008 | 黑医保卡 | 医保卡号在黑名单 | 极高 | 拒绝 | 历史确认风险直接拦截 |
| R009 | 无诊断开药 | 处方无诊断编码或诊断与药品目录不匹配 | 高 | 人工审核 | 防超适应症 / 无指征用药 |
| R010 | 同院高频挂号 | 同一患者 24 小时内同一医院挂号 ≥3 次且取消 ≥2 次 | 中 | 标记 | 占号 / 抢号行为特征 |
| R011 | 夜间结算异常 | 0–5 点医保结算 + 单笔金额 >2000 | 中 | 标记 | 非正常诊疗时段的高额结算 |
| R012 | 医师跨院高频 | 同一医生 7 天内 ≥3 家不同医院出诊并开方 | 高 | 人工审核 | 疑似挂证或跨院统方 |
| R013 | 慢病频繁购药 | 近 30 天 ≥4 次就诊 + 处方总量 ≥12 | 高 | 人工审核 | 慢病患者高频购药，疑似分解处方/超量套取慢病额度 |
| R014 | 分解住院结算 | 结算 ≥6 次 + 平均单次 <1500 | 高 | 人工审核 | 多次低额结算，疑似将住院分解为多次结算套取基金 |
| R015 | 重复购药 | 药品订单 ≥5 + 处方 ≥5 | 高 | 人工审核 | 跨院/跨科重复开药购药，增加基金与用药风险 |
| R016 | 串换药品嫌疑 | 单笔药品订单数量 ≥20 且金额 ≥2000 | 高 | 人工审核 | 数量与金额背离正常处方，疑似串换药品/高价药套保 |
| R017 | 异常高额报销 | 单笔结算 >3000 且报销比例 ≥90% | 高 | 人工审核 | 大额 + 超高报销比例，疑似虚报费用/超标准报销 |
| R018 | 回流药倒卖 | 非本人收药 ≥2 单 + 药品订单 ≥3 | 高 | 人工审核 | 多次非本人收药，疑似收集医保药品回流倒卖 |
| R019 | 夜间频繁结算 | 夜间结算 ≥2 次 + 结算 ≥4 次 | 中 | 标记 | 夜间频繁结算，疑似虚假就医/挂床住院 |
| R020 | 异地大额结算 | 异地结算 ≥2 次 + 单笔最大 >5000 | 高 | 人工审核 | 多次异地大额结算，疑似异地套现/骗保 |

实现约定：

- 每条规则对应 `app/engine/rule.py` 中 1 个 match 函数 + 1 个 score 阈值，注册时 `enabled=True`。
- 规则命中必须输出证据链（命中哪些条件、涉及哪些记录），供前端 case 详情与人工复核使用。
- 规则编号本设计用连续 R001–R020；任务书示例为槽位式编号，实现时以规则表 ID 为准。
- R013-R020 仅使用现有 25 维特征组合（不加新特征，不动 schema），便于在训练/演示数据上直接验证命中效果。
