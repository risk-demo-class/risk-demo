# 演示与录屏清单

## 演示前准备

```powershell
python scripts/init_db.py --reset --yes
python scripts/train_demo_model.py
python scripts/main.py
```

浏览器打开 `http://127.0.0.1:8000`。录屏前确认 `/docs`、仪表盘、规则管理、风险检查、案件、黑名单、Agent 八个入口可访问。

## 建议 8–10 分钟脚本

1. 用 1 分钟说明四类业务边界、8 张业务表与 9 张风控表。
2. 展示规则管理中的 R001、R008、R012、R018、R025、R030，说明 JSON 条件对应特征。
3. 在风险检查页依次演示：
   - 转账：`U002 / TXN_GEO_001`；
   - 信用卡：`U010 / TXN_CC_RISK`；
   - 贷款：`U006 / LOAN_MULTI_1`；
   - 登录：`U008 / LOGIN_PROXY`。
4. 打开评估详情，展示规则分、ML 概率、25 维特征和事件快照。
5. 打开案件页完成审核，再演示用户/设备/IP 黑名单及审计语义。
6. 用 Agent 查询 U002 画像与近 7 天趋势。
7. 展示 `docs/model_metrics.json` 的 `val_auc`、`val_f1` 和特征重要性。
