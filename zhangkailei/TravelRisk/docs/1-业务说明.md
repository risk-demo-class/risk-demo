# 旅游风控业务说明

系统面向 OTA 平台的机票、酒店、签证与支付业务，在预订和支付时实时识别黄牛囤票、签证欺诈、身份冒用、共享支付账号、群控设备、大额跨境和高取消倾向。

## 典型欺诈场景

1. 黄牛使用共享支付账号、设备和 IP，在短时间批量预订同一航班。
2. 有多次拒签记录的用户更换目的地或证件重复提交签证。
3. 新注册、未实名账户突然提交高额跨境订单。
4. 同一证件关联多个账户，或乘客与账户历史常用乘客差异明显。
5. 高取消用户批量占用热门航班或不可退款酒店资源。

关键事件为机票预订、酒店预订、签证申请和订单支付。证件号、手机号和支付账号只保存哈希；风控决策和人工操作必须保留审计记录。

术语：OTA（在线旅游平台）、PNR（旅客订座记录）、拒签、临期行程、关联载体（证件/设备/IP/支付账号）。
