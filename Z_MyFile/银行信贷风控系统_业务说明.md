# 银行信贷风控系统 · 一页纸业务说明

## 一、行业定位
银行信贷风控围绕**借贷全生命周期**而非电商交易：贷前判断"能不能借、是不是骗贷"，贷中控制"钱怎么付"，贷后管理"钱收不收得回、有没有被挪用"。核心矛盾是**信息不对称 + 欺诈黑产**，且受强监管约束，业务对象是借款人（个人/企业）而非用户订单。

## 二、典型欺诈场景（银行特有，与电商完全不同）
| 类别 | 典型场景 | 阶段 |
|---|---|---|
| 身份欺诈 | 冒名贷款（盗用他人身份）、伪造身份证件、一人多证 | 贷前 |
| 材料造假 | 伪造收入证明/银行流水/完税证明；流水余额断裂；证件模板默认值、货币单位异常 | 贷前 |
| 黑产包装 | 包装"征信白户/背债人"、空壳公司+短期补缴公积金虚构资质、伪造工资流水骗贷套现 | 贷前 |
| 团伙欺诈 | 同地址/同手机/同收款账户/同材料模板批量申请；中介集中代办；互保与关联担保；抵押物重复使用（一房多贷）；集体断供失联 | 贷前/贷后 |
| 用途违规 | 经营贷/消费贷资金流入楼市、股市、理财；资金回流借款人/关联方账户；借新还旧 | 贷中/贷后 |
| 信用欺诈（软欺诈） | 多头借贷、频繁硬查询、收入虚高申报、隐瞒负债 | 贷前 |
| 交易/账户风险 | 信用卡套现、涉赌涉诈账户、洗钱、异常资金链 | 贷中/贷后 |
| 内部欺诈 | 内外勾结骗贷、员工篡改审批材料、核心风控环节外包失控 | 全流程 |

## 三、关键业务字段（风控建模核心）
- **身份**：姓名、身份证号（含校验位）、出生日期、性别、婚姻状况、户籍/居住地址、手机号、职业单位
- **申请**：产品类型、申请金额、期限、贷款用途、担保方式、还款方式、放款账号
- **征信**：报告日期、近24月累计/连续逾期、当前逾期、五级分类、呆账/代偿、近6月硬查询次数、未结清贷款、对外担保、被执行人/失信状态
- **收入负债**：月/年收入（收入证明·银行流水·完税证明**三源交叉**）、月均入账、DTI、月供、首付款来源
- **资产担保**：不动产权证（证书编号/权利人/地址）、抵押率、不动产查询结果、评估价值
- **企业经营**：营业执照（名称/统一社会信用代码/法定代表人/成立日期/营业期限）、经营年限、财务报表（会计恒等式/现金流勾稽）、纳税额、特许经营证件、经营痕迹（工资/税金/上下游往来）
- **账户/设备/行为**：银行账号、收款账户、设备指纹、IP/GPS、申请时间、材料元数据（模板指纹/拍照背景/生成软件）
- **关联关系**：关联方与担保关系、共用地址/手机/账户/不动产权证书（知识图谱反欺诈）

## 四、事件类型（全生命周期）
- **业务事件**：申请进件 → 反欺诈核查 → 准入授信 → 审批（自动/人工复核）→ 签约 → 放款（受托支付/自主支付）→ 还款 → 结清/续贷
- **风险事件**：欺诈规则命中、黑名单命中、团伙预警、审批拒绝/转人工、放款资金回流、逾期（M1/M2/M3+）、不良认定、司法处置、催收、核销
- **监管事件**：大额可疑交易报告、涉赌涉诈线索处置（"断卡"）、征信异议处理、反洗钱名单命中

## 五、国内监管红线（合规必须满足）
1. **贷款"三个办法"**（2024 版《固定资产贷款管理办法》《流动资金贷款管理办法》《个人贷款管理办法》，2024-07-01 施行，取代 2010 年旧版）：尽职调查真实性、审贷分离分级审批、受托支付标准、贷后管理
2. **《商业银行互联网贷款管理暂行办法》**：核心风控环节不得外包、合作机构出资比例≥30%、额度与集中度约束
3. **征信监管**（《征信业管理条例》《征信业务管理办法》）：查询须授权并约定用途；信贷决策须综合评价、不得仅凭单条不良信息否决；不良信息保存 5 年；保障异议权/申诉权
4. **数据合规**（《个人信息保护法》《数据安全法》《网络安全法》）：最小必要、告知同意、敏感个人信息单独同意、数据分级与安全评估
5. **反洗钱与涉赌涉诈资金链治理**：KYC 客户身份识别、大额可疑交易报告、账户风险监测、配合"断卡行动"
6. **信贷资金用途监管**：严禁流入楼市、股市、理财市场；大额贷款受托支付；贷后资金回流监控

## 六、风控建设要点
- **贷前**：身份核验（OCR 证件识别 + 公安/三方核验 + 征信授权查询）+ 申请反欺诈规则 + 信用评分；流水/完税/收入多源交叉验证
- **贷中**：额度与利率定价、受托支付执行、放款资金流向监控
- **贷后**：还款监控、资金回流与用途违规预警、关联方及团伙动态监测（知识图谱）
- **内控**：权限分离、审批留痕、模型可解释与定期审计，防范内外勾结
