# 物流（含跨境）行业风控系统业务说明（1 页）

## 1. 业务边界

- 寄递实名：覆盖寄件人/收件人实名核验、面单隐私保护。
- 危险品：覆盖电池、化学品等禁限物品的瞒报识别与安全拦截。
- 跨境物流：覆盖报关清关、三单对碰、海外仓、结汇退税。
- 代收货款：覆盖 COD 下单、派送收款、结算与拒收风险。

## 2. 关键风控场景（重点监控）

- 实名信息异常：寄件人/收件人证件、手机号、地址频繁变化或核验缺失。
- 危险品瞒报：品名与重量、申报价值、电池标记不一致，疑似夹带。
- 跨境包裹异常：重量、申报价值与物品不符，三单不一致或清关异常。
- 代收货款风险：拒收率、退款率、滞留率异常。
- 收件地址异常：偏远地区、临时地址、多人共用地址。
- 寄件行为异常：高频寄件、凌晨寄件、批量寄件。

## 3. 典型欺诈场景

- 刷单与空包件：虚假订单、空包或伪造路由，骗取补贴、评分或流量。
- 理赔欺诈：虚报丢件/破损/延误，骗取保价、运费险或赔偿。
- 代收货款诈骗：利用 COD 向不知情收件人收费，或异常拒收套利。
- 虚假签收与虚假路由：未实际派送或运输，伪造扫描记录。
- 虚假面单与面单买卖：无真实寄递关系，买卖、伪造电子面单。
- 内部舞弊：截留货物、调包、盗卖客户信息、伪造扫描。
- 批量注册与薅羊毛：批量注册寄件账号，套取优惠或结算便利。
- 违禁品与危险品瞒报：夹带禁寄物品、危险品，绕过实名与安检。
- 跨境低报/伪报与三单不符：低报货值、伪报品名，虚假交易骗税骗补。
- 跨境虚假妥投与资金异常：境外未妥投伪造签收，异常结汇或洗钱。

## 4. 关键业务字段

| 字段 | 说明 |
|---|---|
| 运单号 | 国内/跨境运单唯一标识 |
| 寄件人/收件人信息 | 姓名、手机号、地址、是否实名 |
| 物品信息 | 品名、品类、申报价值、重量、体积、保价 |
| 费用信息 | 运费、支付方式、代收货款金额 |
| 节点记录 | 揽收/干线/中转/派送/签收时间与网点 |
| 异常记录 | 破损、丢件、退回、拒收、清关异常 |
| 理赔记录 | 理赔单号、原因、金额、赔付状态 |
| 客户账户 | 客户号、结算账户、信用等级、历史寄递量 |
| 三单信息 | 订单号、支付单号、物流单号及比对结果 |
| 报关信息 | 清单号、贸易方式、HS 编码、币种、原产国/目的国 |
| 海外仓与退件 | 入库/出库、库存差异、退件记录 |
| 设备与行为 | 下单设备、IP、寄件频次（合规采集） |

## 5. 业务事件类型

| 事件类型 | 触发场景 | 主要风险 |
|---|---|---|
| 寄件下单 | 用户提交寄件订单 | 批量注册、虚假面单 |
| 揽收 | 快递员/网点揽收扫描 | 空包、虚假揽收 |
| 中转/分拨 | 干线/分拨中心扫描 | 虚假路由、调包 |
| 派送 | 末端网点派送扫描 | 滞留、虚假派送 |
| 签收 | 本人/代收/驿站/柜机签收 | 虚假签收、代收纠纷 |
| 拒收/退回 | 收件人拒收、退件 | 退件欺诈、异常拒收 |
| 投诉 | 客户发起投诉 | 恶意投诉、敲诈 |
| 理赔申请 | 丢件/破损申请理赔 | 理赔欺诈、内外勾结 |
| 运费/COD 结算 | 运费结算、代收货款打款 | 截留资金、空单套现 |
| 实名认证 | 寄件人身份核验 | 冒名、实名信息异常 |
| 三单对碰/报关清关 | 订单/支付/物流单比对、申报查验 | 三单不符、低报伪报 |
| 海外仓/结汇退税 | 海外仓出入库、收结汇、退税申报 | 库存差异、洗钱骗税 |

## 6. 行业术语表

| 术语 | 含义 |
|---|---|
| 运单/面单 | 记录一票快件寄递信息的单据 |
| 揽收 | 快递员从寄件人处取件并扫描入库 |
| 签收 | 收件人确认收到快件 |
| 代收货款（COD） | 派送时向收件人代收货款再结算给寄件方 |
| 保价 | 寄件人声明价值并支付保费，丢损按声明赔付 |
| 月结客户 | 与物流企业按月结算运费的企业客户 |
| 异常件 | 破损、丢件、滞留、拒收、清关异常等快件 |
| 隐私面单 | 对姓名、电话等个人信息脱敏后的运单 |
| 三单对碰 | 订单、支付单、物流单与报关清单交叉比对 |
| 海外仓 | 设在境外的仓储设施，用于备货、分拣、本地配送 |

## 7. 国内监管合规要求

- 三项安全制度：实名收寄、收寄验视、过机安检。
- 实名制：《邮件快件实名收寄管理办法》要求实名登记与核验。
- 个人信息保护：隐私面单/隐名化、最小化采集、加密存储；跨境传输需依法合规。
- 禁寄物品：《禁止寄递物品管理规定》及指导目录，重点识别危险品。
- 快递服务监管：《快递市场管理办法》对服务、投诉、时限的要求。
- 海关监管：三单一致、如实申报；跨境涉及《出口管制法》与海关禁限品。
- 外汇与反诈：规范收结汇，配合《反电信网络诈骗法》识别可疑寄递。
- 审计留痕：风控决策、操作日志、数据留存满足监管检查。

## 8. 与电商风控的差异

电商以“用户-订单-支付”为主；物流以“运单-节点-人员-结算”为主，更依赖扫描节点时序和内部人员风险；跨境物流还叠加海关、外汇、个人信息出境等强合规约束。

## 9. 后续改造方向（供代码改造参考）

- 事件类型：下单、揽收、派送、签收、投诉、理赔、三单对碰、报关清关、COD 结算等。
- 特征：实名异常、危险品偏离、重量/价值偏离、COD 拒收率、地址异常、寄件频率等。
- 规则与模型：围绕上述特征配置规则，并训练“是否异常件/异常单”二分类模型。
- 保留复用：规则引擎、决策流水线、案件、审计、告警、AI Agent 框架。

### 11.4 模型标签与训练

- 标签：0 = 通过/标记，1 = 人工审核/拒绝。
- 训练数据：`risk_assessment`（ml_score IS NULL） JOIN `risk_feature` 宽表拼 30 维。
- 评估指标：`val_auc`、`val_f1`（当前 200 条训练示例：val_auc=0.8981, val_f1=0.7619）。
