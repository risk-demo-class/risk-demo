# 二、交付产物

**目标**: 业务表 + 数据生成 + 数据校验, 跑通 `init_db` 完整流程.

**输入**: 任务 1 产出的业务说明

**交付物**:

- `app/models_business.py`: 你设计的 N 张业务表的 SQLAlchemy 模型
- `sql/init_business_tables.sql`: 同上的 DDL
- `sql/init_business_data.sql`: 至少 100 条业务数据
- `scripts/gen_business_data.py`: 可重复运行的造数脚本
- `app/service/validator.py`: 业务校验派发表
- 改 `app/config.py`: 黑名单 type 集合 + 业务事件类型枚举

**vibe 提示词模板**:

> 这是我的业务说明: <粘贴任务 1 产出>. 请帮我设计 N 张业务表 schema, 写 SQLAlchemy 模型 + DDL, 设计字段 / 关联 / 索引时要考虑后续风控特征计算的便利. 同时写一个 Python 造数脚本, 至少造 100 条业务数据.

**验收**:

- `init_db` 跑通, 数据库里有 N 张表
- `gen_business_data.py` 跑通, 至少 100 条业务事件入库
- 业务事件类型 >= 3 种

## 类别一：交易反欺诈类（8条）

| 编号   | 规则描述                                                     | 涉及表                                         | SQL实现语句（判断逻辑）                                      |
| :----- | :----------------------------------------------------------- | :--------------------------------------------- | :----------------------------------------------------------- |
| **F1** | 单笔交易金额 ≥ 5万元（且为无卡/快捷支付） → 标记人工确认     | `transaction_order` <br>`product_channel`      | `SELECT 1 FROM transaction_order t JOIN product_channel c ON t.channel_code=c.channel_code WHERE t.txn_amount >= 50000 AND c.channel_type='线上' AND t.txn_status='成功'` |
| **F2** | 单笔交易金额 ≥ 20万元（且非柜面渠道） → 一票否决             | `transaction_order` <br>`product_channel`      | `SELECT 1 FROM transaction_order t JOIN product_channel c ON t.channel_code=c.channel_code WHERE t.txn_amount >= 200000 AND c.is_counter=0 AND t.txn_status='成功'` |
| **F3** | 凌晨0-6点发生首笔大额交易（≥1万元） → 标记                   | `transaction_order` <br>`account_info`（辅助） | `SELECT 1 FROM transaction_order WHERE HOUR(txn_time) BETWEEN 0 AND 6 AND txn_amount >= 10000 AND txn_status='成功' AND NOT EXISTS (SELECT 1 FROM transaction_order t2 WHERE t2.account_id = transaction_order.account_id AND t2.txn_time < transaction_order.txn_time AND t2.txn_amount >= 10000)` |
| **F4** | 密码输入/人脸识别到交易完成间隔 ≤ 3秒 → 疑似程序化           | `transaction_order`                            | `SELECT 1 FROM transaction_order WHERE TIMESTAMPDIFF(SECOND, request_time, txn_time) <= 3 AND request_time IS NOT NULL` |
| **F5** | 单日交易失败次数 ≥ 3次 → 临时锁定账户                        | `transaction_order`                            | `SELECT account_id, COUNT(1) AS fail_cnt FROM transaction_order WHERE DATE(txn_time) = CURDATE() AND txn_status = '失败' GROUP BY account_id HAVING COUNT(1) >= 3` |
| **F6** | 同一设备ID关联账户数 ≥ 3个 → 标记团伙欺诈                    | `transaction_order`                            | `SELECT device_id, COUNT(DISTINCT account_id) AS acc_cnt FROM transaction_order WHERE device_id IS NOT NULL GROUP BY device_id HAVING COUNT(DISTINCT account_id) >= 3` |
| **F7** | 30天内交易对手涉及新开账户（≤7天） ≥ 3笔 → 标记洗钱          | `transaction_order` <br>`account_info`         | `SELECT t.account_id FROM transaction_order t JOIN account_info a ON t.counterparty_account = a.account_id WHERE t.txn_time >= DATE_SUB(NOW(), INTERVAL 30 DAY) AND a.register_time >= DATE_SUB(NOW(), INTERVAL 7 DAY) GROUP BY t.account_id HAVING COUNT(1) >= 3` |
| **F8** | 单日转账笔数 ≥ 50笔（且对手分散） → 冻结账户（注：原属反洗钱，归入此兼容） | `transaction_order`                            | `SELECT account_id, COUNT(DISTINCT counterparty_account) AS cnt FROM transaction_order WHERE DATE(txn_time) = CURDATE() AND txn_type_code = 'TRANSFER' AND txn_status='成功' GROUP BY account_id HAVING COUNT(1) >= 50` |

## 类别二：信贷审批与信用风险类（6条）

| 编号   | 规则描述                                           | 涉及表                             | SQL实现语句（判断逻辑）                                      |
| :----- | :------------------------------------------------- | :--------------------------------- | :----------------------------------------------------------- |
| **C1** | 近3个月征信查询 ≥ 6次（且未放款） → 建议拒贷/降额  | `credit_inquiry_log`               | `SELECT account_id, COUNT(1) AS cnt FROM credit_inquiry_log WHERE inquiry_time >= DATE_SUB(NOW(), INTERVAL 3 MONTH) AND inquiry_reason IN ('贷款审批','信用卡审批') AND is_approved = 0 GROUP BY account_id HAVING COUNT(1) >= 6` |
| **C2** | 信用卡额度使用率 ≥ 90%（且持续3个月） → 资金链紧张 | `credit_card_info`                 | `SELECT account_id FROM credit_card_info WHERE (used_limit / total_limit) >= 0.9 AND update_time >= DATE_SUB(NOW(), INTERVAL 3 MONTH)` |
| **C3** | 当前申请贷款金额 ≥ 月收入 20倍 → 一票否决          | `loan_info` <br>`account_info`     | `SELECT l.account_id FROM loan_info l JOIN account_info a ON l.account_id = a.account_id WHERE l.loan_amount >= a.monthly_income * 20 AND a.monthly_income IS NOT NULL` |
| **C4** | 贷款用途为“投资/购房” → 一票否决（消费贷违规）     | `loan_info`                        | `SELECT 1 FROM loan_info WHERE loan_purpose IN ('投资','购房','炒股')` |
| **C5** | 近6个月有逾期 ≥ 30天（且金额≥1000元） → 降低额度   | `repayment_record` <br>`loan_info` | `SELECT r.loan_id FROM repayment_record r JOIN loan_info l ON r.loan_id = l.loan_id WHERE r.repay_time >= DATE_SUB(NOW(), INTERVAL 6 MONTH) AND r.is_late = 1 AND r.late_days >= 30 AND r.repay_amount >= 1000` |
| **C6** | 在 ≥3家机构有未结清贷款 → 多头借贷，建议拒贷       | `loan_info`                        | `SELECT account_id, COUNT(DISTINCT lender_org) AS org_cnt FROM loan_info WHERE repay_status NOT IN ('结清','核销') GROUP BY account_id HAVING COUNT(DISTINCT lender_org) >= 3` |

## 类别三：反洗钱（AML）与合规风控类（7条）

| 编号   | 规则描述                                                     | 涉及表                                     | SQL实现语句（判断逻辑）                                      |
| :----- | :----------------------------------------------------------- | :----------------------------------------- | :----------------------------------------------------------- |
| **A1** | 单日累计现金存取 ≥ 5万元（无合理用途） → 大额上报            | `transaction_order` <br>`transaction_type` | `SELECT t.account_id, SUM(t.txn_amount) AS total FROM transaction_order t JOIN transaction_type tt ON t.txn_type_code = tt.txn_type_code WHERE DATE(t.txn_time) = CURDATE() AND tt.is_cash = 1 AND t.txn_status='成功' GROUP BY t.account_id HAVING SUM(t.txn_amount) >= 50000` |
| **A2** | 资金到账后 **5分钟内** 即转出（快进快出） → 标记高风险       | `account_balance_log`                      | `-- 自连接查询：入账后5分钟内发生出账 SELECT a1.account_id FROM account_balance_log a1 JOIN account_balance_log a2 ON a1.account_id = a2.account_id WHERE a1.change_amount > 0 AND a2.change_amount < 0 AND TIMESTAMPDIFF(MINUTE, a1.change_time, a2.change_time) <= 5 AND a2.change_time > a1.change_time` |
| **A3** | 接收来自 **≥3个** 不同非关联方的大额转账（单笔≥1万） → 人工核查 | `transaction_order` <br>`account_info`     | `SELECT account_id, COUNT(DISTINCT counterparty_account) AS cnt FROM transaction_order WHERE txn_type_code = 'TRANSFER_IN' AND txn_amount >= 10000 AND txn_time >= DATE_SUB(NOW(), INTERVAL 30 DAY) GROUP BY account_id HAVING COUNT(DISTINCT counterparty_account) >= 3`（关联方排除需另建关系表） |
| **A4** | 对手方位于 **高风险国家/地区**（制裁名单） → 一票否决        | `transaction_order` <br>`blacklist`        | `SELECT 1 FROM transaction_order t JOIN blacklist b ON t.country_code = b.target_value WHERE b.target_type = '国家地区' AND b.expire_time IS NULL` |
| **A5** | 公转私：单笔对公账户转个人账户 ≥ 50万元 → 标记               | `transaction_order` <br>`account_info`     | `SELECT t.* FROM transaction_order t JOIN account_info a1 ON t.account_id = a1.account_id JOIN account_info a2 ON t.counterparty_account = a2.account_id WHERE a1.account_type = '企业' AND a2.account_type = '个人' AND t.txn_amount >= 500000 AND t.txn_status='成功'` |
| **A6** | 单日转账笔数 ≥ 50笔（且对手分散） → 冻结（同F8，此处复用）   | `transaction_order`                        | 同F8                                                         |
| **A7** | 累计转入资金 ≥ 100万元 → 标记高净值/加强尽调                 | `account_info`                             | `SELECT account_id FROM account_info WHERE total_in_amount >= 1000000` |

## 类别四：账户与行为异常类（7条）

| 编号   | 规则描述                                                     | 涉及表                                       | SQL实现语句（判断逻辑）                                      |
| :----- | :----------------------------------------------------------- | :------------------------------------------- | :----------------------------------------------------------- |
| **B1** | 近3个月无任何交易，突然发生 ≥1万元转出 → 疑似盗用            | `account_info` <br>`transaction_order`       | `SELECT t.account_id FROM transaction_order t JOIN account_info a ON t.account_id = a.account_id WHERE t.txn_amount >= 10000 AND t.txn_status='成功' AND (a.last_txn_time IS NULL OR DATEDIFF(t.txn_time, a.last_txn_time) >= 90)` |
| **B2** | 频繁修改绑定手机号/邮箱（7天内 ≥2次） → 限制大额交易         | `user_operation_log`                         | `SELECT account_id, COUNT(1) AS cnt FROM user_operation_log WHERE op_type IN ('修改手机号','修改邮箱','修改密码') AND op_time >= DATE_SUB(NOW(), INTERVAL 7 DAY) AND op_result='成功' GROUP BY account_id HAVING COUNT(1) >= 2` |
| **B3** | 设备/网络环境异常（模拟器、VPN代理） → 所有操作高风险        | `transaction_order`                          | `SELECT 1 FROM transaction_order WHERE device_env IN ('模拟器','越狱','VPN')` |
| **B4** | 用户累计转入资金 ≥ 100万元 → 高净值（同A7）                  | `account_info`                               | 同A7                                                         |
| **B5** | 密码找回/信息修改后 **1小时内** 发起转账 → 一票否决          | `user_operation_log` <br>`transaction_order` | `SELECT t.txn_id FROM transaction_order t JOIN user_operation_log u ON t.account_id = u.account_id WHERE u.op_type IN ('找回密码','修改密码') AND u.op_time >= DATE_SUB(t.request_time, INTERVAL 1 HOUR) AND u.op_time <= t.request_time AND t.txn_status='成功'` |
| **B6** | 同一设备ID关联账户 ≥ 3个（同F6）                             | `transaction_order`                          | 同F6                                                         |
| **B7** | 沉睡账户突然大额转出（即B1的变体，使用`last_txn_time`精准判定） | `account_info` <br>`transaction_order`       | `SELECT t.account_id FROM transaction_order t JOIN account_info a ON t.account_id = a.account_id WHERE t.txn_amount >= 10000 AND t.txn_time >= DATE_SUB(NOW(), INTERVAL 1 DAY) AND (a.last_txn_time IS NULL OR TIMESTAMPDIFF(DAY, a.last_txn_time, t.txn_time) >= 90)` |
