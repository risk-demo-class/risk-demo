# 银行风控业务说明

本项目模拟零售银行的信用卡交易、转账、贷款申请和登录四类事件。系统用于教学演示：以合成数据说明规则引擎、XGBoost 与案件闭环如何协作，不使用真实个人或金融数据。

## 典型欺诈场景

- 账户盗用：攻击者在新设备或代理 IP 上登录后发起交易。
- 异地大额转账：交易地点偏离常用地点且金额异常高。
- 设备群控：同一设备关联多个用户，短时间执行重复操作。
- 多卡资金归集：多张来源卡在一小时内向同一收款方集中转入。
- 贷款申请欺诈：短期内多次申请贷款，负债率高或身份信息可疑。

## 关键字段与事件

关键字段包括用户ID、身份证哈希、信用分、KYC等级、负债率、银行卡哈希、交易金额、交易渠道、收款方、设备指纹、IP、地理位置、贷款期限和登录结果。

事件类型为：信用卡交易、转账、贷款申请、登录。请求统一使用 `event_type`、`source_id`、`user_id`、`event_data` 四个必需字段。

## 术语表

| 术语 | 含义 |
| --- | --- |
| KYC | 客户身份识别等级 |
| 设备指纹 | 用于识别终端的稳定哈希 |
| 代理 IP | 经代理服务器转发的网络地址 |
| Tor 出口 | 匿名网络对外访问节点 |
| 资金归集 | 多个来源向同一收款方集中转入 |
| 一票否决 | 命中极高风险规则后强制拒绝 |
