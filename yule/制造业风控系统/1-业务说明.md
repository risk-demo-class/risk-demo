# 制造业风控系统 - 业务说明

> 行业: 制造业 (场景 D: 经销商订货 / 设备保修 / 采购订单 / 售后维修)
> 系统定位: 面向制造企业渠道体系的 B 端风控系统, 风控对象是**经销商**而非 C 端消费者。

## 一、行业背景与风控目标

制造企业通常通过**区域授权经销商**销售设备 (机床、注塑机、空压机等), 厂商按区域授权、按合同供货, 并提供整机保修与售后维修服务。相比电商 C 端欺诈 (刷单、薅羊毛), 制造业的典型风险集中在**渠道窜货、套保骗保、囤货倒卖、资质管理**四大类, 单笔金额大 (几十万到上百万), 一旦发生损失严重。

## 二、典型欺诈场景 (>= 3 种)

| 场景 | 描述 | 危害 |
|---|---|---|
| **跨区串货** | 经销商把货卖到授权区域之外, 冲击其他区域价格体系, 常被区域伙伴举报 | 渠道价格体系崩溃 |
| **套保骗保** | 已过保修期的设备频繁报修, 或同一台设备 90 天内多次保修, 套取厂商免费维修服务 | 维修成本虚高 |
| **大额囤货倒卖** | 经销商一次性超量订货 (>100 台) 或新签约经销商首单异常大, 疑似低价囤货后倒卖 | 扰乱市场秩序 |
| **维修费用虚高** | 单次维修费超过设备官方建议零售价 (MSRP) 60%, 与维修工合谋虚报 | 直接资金损失 |
| **资质过期仍订货** | 经销商合同已到期仍继续下单, 渠道管理失效 | 合规风险 |

## 三、关键业务字段 (>= 10 个)

- `dealer_id` — 经销商 ID (风控主体)
- `dealer_level` — 经销商等级 (核心/授权/普通)
- `region` / `ship_to_region` — 授权区域 / 实际发货区域 (串货判断核心)
- `contract_start` / `contract_end` — 合同起止时间 (资质判断)
- `product_id` / `model` — 产品 ID / 型号
- `msrp` — 官方建议零售价 (维修费占比基准)
- `warranty_months` — 保修期月数 (保修期外判断)
- `order_id` / `quantity` / `unit_price` / `total_amount` — 订单四要素
- `product_sn` — 设备序列号 (套保追踪)
- `issue_date` / `repair_cost` / `technician_id` — 报修时间 / 维修费 / 维修工

## 四、业务事件类型 (>= 3 种)

| 事件类型 | source_id | 典型风险 |
|---|---|---|
| **经销商订货** | order_id | 大额囤货 / 跨区发货 / 资质过期 / 新经销商大单 |
| **设备保修** | warranty_id | 保修期外高频 / 套保 / 维修费虚高 |
| **跨区串货举报** | report_id | 串货拦截 / 黑经销商特征 |

## 五、行业术语表 (>= 5 个)

- **串货**: 经销商将产品销往授权区域之外的行为。
- **套保/骗保**: 通过反复报修、保修期外报修等套取厂商免费维修服务。
- **MSRP**: 官方建议零售价 (Manufacturer's Suggested Retail Price)。
- **产品 SN**: 设备序列号, 一机一号, 用于保修与防串货追踪。
- **渠道体系**: 厂商→区域授权经销商→终端用户的销售网络。
- **囤货**: 经销商超量订货以低价倒卖或占额度。

## 六、监管与合规提示

- 渠道价格管控依据《反不正当竞争法》与厂商渠道协议, 串货举报需留痕 (举报人/时间/区域)。
- 保修服务涉及消费者权益保护与产品三包规定, 套保识别应避免误伤正常保修客户。
- 经销商资质 (合同/授权) 管理应形成闭环: 合同到期即冻结订货权限, 系统给出风控提示。
