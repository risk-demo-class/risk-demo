# 银行业分析

本项目面向银行客户、资金交易、贷款申请和登录安全四类风险识别场景，不接入真实征信、真实放款或真实敏感信息。系统重点识别账户接管、异地大额转账、设备团伙、多头借贷、代理网络和 KYC 不足等风险。

与电商风控相比，银行业务的核心对象从订单和收货地址切换为客户、银行卡、交易、贷款、登录、设备和 IP。风险判断更依赖交易链路、设备复用、地理位置、时间窗口、额度和客户身份状态；身份证、银行卡、IP 与设备指纹必须使用哈希、脱敏或虚拟值。四类事件统一通过 `RiskCheckRequest(event_type, source_id, user_id, event_data)` 进入事件驱动流水线，保留风险事件、特征快照、评估、案件和审计闭环。

本原型采用规则与 XGBoost 双轨融合：规则负责可解释的银行底线，模型负责组合风险；命中极高风险规则时保留 veto，模型低分不能推翻拒绝结果。
