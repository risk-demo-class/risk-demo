# 银行业务表设计

业务层共 8 张表，风控核心 9 张表保持独立。

| 表 | 核心字段 | 用途 |
|---|---|---|
| `bank_user_info` | `user_id`, `id_card_hash`, `credit_score`, `kyc_level`, `account_status` | 客户身份、KYC、信用与账户状态 |
| `bank_card` | `card_id`, `user_id`, `card_no_hash`, `bank_code`, `card_status` | 脱敏银行卡及持卡人关系 |
| `bank_transaction` | `txn_id`, `from_card`, `to_card`, `user_id`, `amount`, `device_id`, `ip`, `txn_time` | 大额转账和交易链路事实 |
| `loan_application` | `loan_id`, `user_id`, `amount`, `debt_ratio`, `application_at` | 贷款申请与负债风险 |
| `login_log` | `login_id`, `user_id`, `device_id`, `ip`, `success`, `login_at` | 登录行为、渠道和时间窗口 |
| `device_fingerprint` | `device_id`, `user_id`, `fingerprint_hash`, `is_emulator` | 设备复用、模拟器和团伙关联 |
| `ip_geo_location` | `ip`, `province`, `city`, `is_proxy`, `is_tor` | IP 地理和代理/Tor 风险标签 |
| `bank_blacklist_extra` | `blacklist_type`, `blacklist_value`, `reason`, `expire_at` | 银行专属设备、IP、银行卡、身份证黑名单 |

所有身份证、银行卡、手机号、IP 和设备指纹样本均使用虚拟值或哈希值。
