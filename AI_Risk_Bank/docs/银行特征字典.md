# 银行特征字典

25 个特征沿用统一输入契约，缺失数据返回 `0.0`，不使用随机数。

## 客户行为 14 维

| 特征族 | 银行口径 |
|---|---|
| `user_total_orders`, `user_orders_30d`, `user_orders_7d` | 客户历史交易总量及时间窗口交易数 |
| `user_total_amount`, `user_avg_order_amount`, `user_max_order_amount` | 历史交易金额、均值和最大值 |
| `user_refund_count`, `user_refund_rate`, `user_refund_amount`, `user_cancel_count` | 银行异常交易/冲正代理指标 |
| `user_postsale_count`, `user_postsale_rate` | 历史贷款申请频次及占比代理指标 |
| `user_complaint_count` | 客户风险投诉/异常记录计数 |
| `user_address_count` | 客户关联设备数量 |

## 当前业务 8 维

`order_total_amount` 对应交易/申请金额；`order_item_count` 对应关联实体数量；`order_sku_count` 对应短时交易或关联卡数量；`order_discount_amount` 保留为黑卡前置兼容字段；`order_discount_rate`、`order_pay_interval_sec`、`order_category_count` 为统一契约下的银行当前业务代理指标；`order_is_night` 表示凌晨时段。

## 设备与地理 3 维

`addr_total_count` 为客户历史设备数；`addr_province_count` 为历史交易/登录省份数；`addr_is_new` 为当前设备是否首次出现。来源为 `device_fingerprint`、`login_log`、`bank_transaction` 和 `ip_geo_location`。

特征快照写入 `risk_feature`，与 `risk_event`、`risk_assessment` 通过事件 ID 回溯。
